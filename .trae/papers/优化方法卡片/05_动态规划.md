## 概述

动态规划将多阶段决策问题分解为一系列子问题，利用最优子结构（子问题最优解构成原问题最优解）和重叠子问题（相同子问题多次出现）递推求解。

**Bellman 最优性原理**：最优策略的子策略也是最优的。

---

## 适用场景

| 特征 | 判断条件 |
|------|---------|
| 多阶段决策 | 决策按时间/阶段顺序进行 |
| 最优子结构 | 当前阶段的最优决策仅依赖于前一阶段状态 |
| 无后效性 | 当前决策不影响之前阶段的状态 |
| 典型场景 | 资源分配、库存控制、路径规划、背包问题、生产调度 |

---

## 求解方法

### 标准 DP 递推

```
状态定义: dp[i][s] = 第 i 阶段、状态 s 时的最优值
状态转移: dp[i][s] = max/min { dp[i-1][s'] + cost(s', s) }
边界条件: dp[0][s₀] = 初始值
```

### 实现方式

| 方式 | 适用 | 说明 |
|------|------|------|
| **自底向上（递推）** | 状态转移方向明确 | 从边界条件出发，逐步推向最终阶段 |
| **自顶向下（记忆化）** | 状态空间大但实际访问少 | 递归 + 缓存，按需计算 |
| **状态压缩** | 当前状态仅依赖上一阶段 | 用一维数组替代二维，节省空间 |

---

## 复杂度分析

| 因素 | 对复杂度的影响 |
|------|---------------|
| 阶段数 N | O(N) |
| 每阶段状态数 S | O(S) |
| 每状态转移选项数 D | O(D) |
| **总复杂度** | **O(N × S × D)** |

---

## 关键参数

| 参数 | 说明 |
|------|------|
| 状态定义 | 最关键的设计决策，决定复杂度和正确性 |
| 状态空间大小 | 应 ≤ 10⁶（内存）或 ≤ 10⁸（时间可接受） |
| 转移方程 | 必须覆盖所有可能的状态转移 |
| 边界条件 | 不可遗漏，通常为 dp[0][*] 或 dp[*][0] |

---

## 常见 DP 模式

| 模式 | 状态定义 | 示例 |
|------|---------|------|
| 线性 DP | dp[i] = 前 i 个元素的最优解 | 最长递增子序列 |
| 背包 DP | dp[i][w] = 前 i 个物品、容量 w 的最优解 | 0-1 背包 |
| 区间 DP | dp[l][r] = 区间 [l, r] 的最优解 | 矩阵链乘 |
| 树形 DP | dp[u][0/1] = 节点 u 选/不选的最优解 | 最大独立集 |
| 状压 DP | dp[mask][i] = 状态 mask 下的最优解 | TSP（小规模） |

## 注意事项

- **状态定义是 DP 的灵魂**：错误的状态定义会导致维度爆炸或遗漏约束
- **状态空间爆炸**：若 N×S×D > 10⁸，考虑状态压缩、启发式剪枝或改用近似算法
- **无后效性必须验证**：若当前决策影响之前状态，DP 不适用
- **连续状态 DP**：若状态为连续变量，需离散化或改用微分动态规划
