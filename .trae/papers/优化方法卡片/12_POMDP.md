# 12 POMDP（部分可观察马尔可夫决策过程）

> 优化方法卡片。Agent 1 阶段 3 算法选择时查阅。条件触发：特征指纹 `uncertainty = "stochastic"` + `time_dependence = "multi_period"` + 状态部分可观察（决策者仅知当前观测、不知真实状态与未来）。

---

## 概述

POMDP 是马尔可夫决策过程（MDP）的扩展，处理**状态部分可观察**的序贯决策问题：决策者无法直接观测系统真实状态，只能基于观测（observation）推断信念状态（belief state），在信念状态上做最优决策。

**与 MDP 的区别**：MDP 假设决策者完全知晓当前状态；POMDP 仅能观测到与真实状态相关的观测信号，需维护信念分布 b(s) = P(state=s | observation history)。

**与随机规划的区别**：随机规划通常是单阶段或两阶段决策；POMDP 是多阶段序贯决策，且每阶段决策基于部分观察，需动态更新信念。

---

## 适用场景

| 特征 | 判断条件 |
|------|---------|
| 多阶段决策 | 决策按时间/阶段顺序进行，存在时序依赖 |
| 状态不确定性 | 系统真实状态不可直接观测，仅有间接观测信号 |
| 观测依赖 | 后续决策依赖于历史观测序列（如"已知未来若干期内某事件不发生"约束了状态分布） |
| 典型场景 | 机器人导航（传感器噪声）、医疗诊断（症状≠病因）、库存决策（需求分布未知）、资源勘探（储量未知） |

**识别要点**：题目中出现"决策者仅知道当前观测、不知道真实状态或未来"类表述 → 状态部分可观察 → POMDP 而非 MDP。

---

## 标准形式

POMDP 由七元组 (S, A, T, R, Z, O, γ) 定义：

```
S: 状态集合（如环境状态的所有可能组合）
A: 行动集合（如移动/等待/采购/检测）
T(s, a, s'): 状态转移函数 P(s' | s, a)
R(s, a): 奖励函数（在状态 s 采取行动 a 的收益）
Z: 观测集合（如当期可观测信号）
O(s', a, z): 观测函数 P(z | s', a)（行动 a 后到达 s' 观测到 z 的概率）
γ: 折现因子（0 < γ < 1）
```

**信念状态更新**（Bayes 滤波）：
```
b'(s') = η · O(s', a, z) · Σ_s T(s, a, s') · b(s)
其中 η 为归一化常数
```

## 求解方法

| 方法 | 适用 | 说明 |
|------|------|------|
| **Value Iteration（值迭代）** | 状态空间小、信念空间可离散化 | 经典精确算法，迭代求解信念状态值函数 V*(b)；复杂度高，适合 |S|≤20 |
| **MCTS（蒙特卡洛树搜索）** | 状态空间大、需在线决策 | POMCP（Partially Observable Monte Carlo Planning）变体，用蒙特卡洛采样近似信念状态值函数；适合实时决策 |
| **滚动 horizon LP（滚动时域线性规划）** | 线性化后可解、需快速响应 | 每阶段用 LP 求解未来 N 步最优决策，仅执行第一步，下阶段重求；适合在线滚动决策 |
| **PBVI（Point-Based Value Iteration）** | 信念空间连续但可采样 | 在信念空间采样有限点集上做值迭代，适合连续信念分布 |
| **SARSOP** | 大规模 POMDP | 基于采样逼近最优值函数，是 PBVI 的改进版 |

---

## 复杂度分析

| 因素 | 对复杂度的影响 |
|------|---------------|
| 状态数 |S| | 指数级影响，|S|>20 时精确算法不可行 |
| 行动数 |A| | 线性影响 |
| 观测数 |Z| | 影响信念更新复杂度 |
| 阶段数 T | O(T) |
| 信念空间维度 | |S|-1 维单纯形 | 精确算法的瓶颈，连续信念需采样逼近 |

**精确 vs 近似**：精确 Value Iteration 适合小规模（|S|≤20, T≤30）；大规模必须用 MCTS/PBVI/SARSOP 等近似算法。

---

## 关键参数

| 参数 | 说明 |
|------|------|
| 折现因子 γ | 长期收益权重，γ→1 重视未来，γ→0 重视当下；无限期 POMDP 必须 γ<1 保证收敛 |
| 信念初始化 b₀ | 初始信念分布，影响前若干阶段决策；通常用先验分布或均匀分布 |
| 观测噪声 | 观测与真实状态的相关性；噪声越大决策越保守 |
| 求解精度 ε | Value Iteration 收敛阈值 |

## 🚫 禁忌（P0 强制）

- **禁止将"代表性场景求确定性最优 + 蒙特卡洛验证"作为 POMDP 主算法**——此为确定性等价（certainty equivalent）简化，仅作上界参考，不产出真正的 POMDP 期望值。代表性场景下的最优策略在非代表性场景序列下大概率失败（蒙特卡洛偏差可能 >50%，且固定策略在多数场景序列下可行率显著下降），仅作上界参考。
- **禁止将 perfect information upper bound 命名为 expected value**——上界（已知全部不确定性信息下的最优值）与期望值（基于随机变量分布的期望收益）是完全不同的概念，命名混同将误导下游消费者。
- **禁止仅报告上界而不报告期望值**——POMDP 决策的核心是期望值最大化，仅报上界让评审无法判断真实决策质量。
- **禁止跳过信念状态更新**——每阶段决策必须基于信念分布 b(s)，而非直接用最近一次观测当真实状态。

## 强制声明（design_critique 标注）

若因工具链/时间/复杂度限制，本题未采用真正的 POMDP 算法（Value Iteration/MCTS/滚动 horizon LP 等）而用了简化方法（如代表性场景+蒙特卡洛），必须在 `modeling_plan.json` 的 `design_critique` 字段显式标注"建模遗留项"：

```json
"design_critique": {
  "pomdp_simplification": {
    "actual_method": "representative_scenario + monte_carlo_validation",
    "should_be": "Value Iteration / MCTS / 滚动 horizon LP",
    "deviation_reason": "时间/工具链限制，未实现真正 POMDP 求解器",
    "impact": "代表性场景求确定性最优仅作上界参考，蒙特卡洛期望值低于上界（偏差>X%），结论仅作上界参考",
    "todo": "正式比赛须实现 POMCP 或 PBVI 等近似 POMDP 求解器"
  }
}
```

## 常见错误

- **混淆 perfect information upper bound 与 expected value**：上界假设已知全部不确定性信息，期望值基于分布的概率平均。两者差距大说明不确定性影响显著，**必须在论文中明确区分**（条件触发：若为 POMDP 类，必须区分 perfect information upper bound 与 expected value，否则扣分）。
- **信念更新遗漏**：每阶段决策未基于最新观测更新信念，导致决策基于过期信息。
- **观测模型与转移模型混淆**：O(s', a, z) 是观测函数，T(s, a, s') 是转移函数，两者不可互换。
- **折现因子 γ=1 在无限期 POMDP 中导致不收敛**：无限期必须 γ<1。
- **代表性场景选择偏差**：选某"平均场景"作为代表性场景，但该场景在真实分布中概率极低，导致策略在多数场景下失败。
