# 04 多目标优化（MOO）

> 优化方法卡片。Agent 1 阶段 3 算法选择时查阅。条件触发：`overlays` 含 MOO。主类型仍为规划类；加权/ε-约束走 `solver_backend`，禁止把 `problem_type` 写成 MOO。NSGA 仅作辅（见工具链优先级）。
> 代码模板：`code_templates/solver_backend.py`（主，加权/ε约束）＋ `code_templates/metaheuristic_solver.py`（辅，NSGA 类搜索）

---

## 概述

多目标优化同时优化 ≥2 个互相冲突的目标函数。不存在使所有目标同时最优的单一解，需要寻找 Pareto 最优解集（非劣解集）。

**标准形式**：
```
min  [f₁(x), f₂(x), ..., fₖ(x)]
s.t. g(x) ≤ 0, h(x) = 0
```

**Pareto 最优**：不存在另一个解 x'，使所有目标不劣于 x 且至少一个目标严格优于 x。

---

## 适用场景

| 特征 | 判断条件 |
|------|---------|
| 目标数量 | ≥2 个互相冲突的目标 |
| 典型场景 | 成本 vs 质量、收益 vs 风险、效率 vs 公平、时间 vs 成本 |
| 关键判断 | 有主次 → 主类型按主目标的规划类，overlays 含 MOO；不能合并为单目标时同样叠加 MOO，**不把** problem_type 改成 MOO |

---

## 处理方法

### 方法 1：权重法（加权求和）

```
min  Σ wᵢ · fᵢ(x)
s.t. g(x) ≤ 0, h(x) = 0, Σ wᵢ = 1, wᵢ ≥ 0
```

| 优点 | 缺点 |
|------|------|
| 简单，可复用 LP/NLP/MIP 求解器 | 权重主观，非凸前沿遗漏 |
| 适合目标量纲接近时 | 不同权重可能得到同一点 |

**权重选择**：应来自题目要求或客观标准，不能主观拍板。建议做权重敏感性分析。

### 方法 2：ε-约束法

```
min  f₁(x)
s.t. f₂(x) ≤ ε₂, f₃(x) ≤ ε₃, ..., fₖ(x) ≤ εₖ
     g(x) ≤ 0, h(x) = 0
```

| 优点 | 缺点 |
|------|------|
| 可得到非凸 Pareto 前沿上的点 | ε 的选取需要经验 |
| 适合主目标明确时的场景 | 计算量随 ε 组合数增长 |

### 方法 3：目标规划

```
min  Σ (d⁺ᵢ + d⁻ᵢ)
s.t. fᵢ(x) + d⁻ᵢ - d⁺ᵢ = targetᵢ
     d⁺ᵢ, d⁻ᵢ ≥ 0
```

| 优点 | 缺点 |
|------|------|
| 适合有明确目标值（≥/≤ target）的场景 | 目标值需预先设定 |
| 可分级（优先满足高优先级目标） | 目标值设定主观 |

### 方法 4：进化算法（NSGA-II / MOEA/D）

| 优点 | 缺点 |
|------|------|
| 一次运行获得完整 Pareto 前沿 | 无最优性保证 |
| 适合非凸、非连续、黑箱目标 | 计算量大，需多次运行 |

---

## 关键参数

| 方法 | 参数 | 建议值 |
|------|------|:---:|
| 权重法 | 权重组合数 | ≥5 组（均匀分布） |
| ε-约束 | ε 范围 | 单目标最优值 ±20% |
| NSGA-II | 种群大小 | 100-200 |
| NSGA-II | 迭代代数 | 200-500 |
| NSGA-II | 交叉概率 | 0.9 |
| NSGA-II | 变异概率 | 1/n（n=变量数） |

---

## 决策方法（从 Pareto 前沿选最终解）

| 方法 | 适用场景 |
|------|---------|
| **TOPSIS** | 有理想解时（距理想解最近） |
| **最小曼哈顿距离** | 各目标同等重要 |
| **拐点法** | 前沿有明显拐点时 |
| **边际替代率** | 可量化目标间权衡时 |

## 注意事项

- **权重法不能找到非凸 Pareto 前沿上的点**，若前沿可能非凸 → 用 ε-约束法或 NSGA-II
- **权重敏感性分析必须做**：换一组权重结论是否剧烈变化？
- **Pareto 前沿可视化**：≤3 目标可画 2D/3D 图，>3 目标用平行坐标图
- **多目标不等同于多子问题**：每个子问题可能是单目标，多目标是一个子问题有多个目标
