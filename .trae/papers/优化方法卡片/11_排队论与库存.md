## 概述

排队论研究服务系统中顾客到达、等待、服务的随机过程，优化目标通常是平衡服务成本与等待成本。库存优化研究多周期库存管理，确定最优订货量/订货点。

---

## 排队论

### 核心参数

| 符号 | 含义 | 典型值 |
|------|------|--------|
| λ | 到达率（顾客/时间） | 从数据估计 |
| μ | 服务率（顾客/时间/服务台） | 决策变量 |
| c | 服务台数 | 决策变量 |
| ρ | 利用率 = λ/(c·μ) | <1（稳定条件） |

### Kendall 记号：A/B/c/K

- A：到达间隔分布（M=指数，D=确定，G=一般）
- B：服务时间分布（同上）
- c：服务台数
- K：系统容量（省略=无限）

### 经典模型

| 模型 | L_q（平均排队长度） | W_q（平均等待时间） |
|------|---------------------|---------------------|
| M/M/1 | ρ²/(1-ρ) | L_q/λ |
| M/M/c | P₀·(cρ)^c·ρ/(c!·(1-ρ)²) | L_q/λ |
| M/G/1 | (λ²σ²+ρ²)/(2(1-ρ)) | L_q/λ |

其中 P₀ 为 M/M/c 系统空闲概率，σ² 为服务时间方差。

### 优化目标

```
min  c_s·c + c_w·L（服务成本 + 等待成本）
s.t. ρ < 0.9（稳定性 + 余量）
     W_q ≤ W_max（等待时间约束）
     P(W > T) ≤ α（服务等级约束）
```

## 库存优化

### 核心参数

| 符号 | 含义 |
|------|------|
| D | 需求率（单位时间） |
| K | 固定订货成本 |
| h | 单位持有成本（单位时间） |
| p | 单位缺货成本 |
| Q | 订货量（决策变量） |
| R | 再订货点（决策变量） |

### 经典模型

| 模型 | 公式 | 假设 |
|------|------|------|
| **EOQ** | Q* = √(2KD/h) | 确定性需求，无缺货，瞬时补货 |
| **EOQ with backorder** | Q* = √(2KD(h+p)/hp) | 允许缺货 |
| **报童模型** | Q* = F⁻¹(p/(p+h)) | 单周期，随机需求，F 为需求 CDF |
| **(s, S) 策略** | 库存 ≤ s 时订货至 S | 周期性检查 |
| **(Q, R) 策略** | 库存 ≤ R 时订货 Q | 连续性检查 |

## 注意事项

- **稳态假设**：排队公式仅适用于稳态（ρ<1），瞬态需仿真
- **分布假设**：M/M/c 假设泊松到达和指数服务，需检验数据是否支持
- **EOQ 假设**：需求恒定、成本恒定，若不符合需用动态模型
- **报童模型的关键**：p/(p+h) 的临界分位数，缺货成本需合理估计
