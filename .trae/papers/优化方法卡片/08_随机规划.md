# 08 随机规划

> 优化方法卡片。Agent 1 阶段 3 算法选择时查阅。条件触发：特征指纹 `uncertainty = "stochastic"`。

---

## 概述

随机规划处理参数不确定但概率分布已知（或可估计）的优化问题。与确定性优化的区别在于：决策需在随机参数实现之前做出，需考虑不确定性对约束满足和目标的影响。

---

## 适用场景

| 特征 | 判断条件 |
|------|---------|
| 参数不确定性 | 部分参数为随机变量，分布已知或可从数据估计 |
| 决策时序 | 存在"here-and-now"决策（随机参数实现前） |
| 典型场景 | 库存管理（随机需求）、投资组合（随机收益）、供应链（随机供应） |

---

## 三类模型

### 1. 期望值模型（Expected Value）

```
min  E[f(x, ξ)]
s.t. g(x) ≤ 0
```

用随机参数的期望值替代随机变量，转化为确定性优化。**最简单但忽略风险**。

### 2. 机会约束规划（Chance-Constrained）

```
min  f(x)
s.t. P{g(x, ξ) ≤ 0} ≥ 1 - α
```

约束以概率 ≥ 1-α 被满足。α=0.05 表示允许 5% 的约束违反概率。

**等价转化**（ξ 服从正态分布时）：
```
若 g(x, ξ) = a(ξ)^T x - b(ξ)，ξ ~ N(μ, Σ)
则 P{g ≤ 0} ≥ 1-α  ⇔  μ^T x + Φ⁻¹(1-α)·√(x^T Σ x) ≤ 0
```

### 3. 带补偿的随机规划（Recourse）

```
min  c^T x + E[Q(x, ξ)]
s.t. Ax = b, x ≥ 0
其中 Q(x, ξ) = min{q^T y | Wy = h - Tx, y ≥ 0}
```

第一阶段决策 x 在 ξ 揭示前做出，第二阶段（补偿）决策 y 在 ξ 揭示后调整。

---

## 求解方法

| 方法 | 适用 | 说明 |
|------|------|------|
| **期望值替代** | 方差小，风险中性 | 直接求解，简单 |
| **机会约束 → 确定性等价** | 正态分布假设成立 | 数学推导后求解 |
| **样本平均近似（SAA）** | 分布复杂 | 蒙特卡洛采样 → 确定性大问题 |
| **L-shaped 方法** | 二阶段 recourse | Benders 分解的随机版本 |
| **场景树 + 求解器** | 离散场景 | 构建场景树，直接求解扩大的确定性模型 |

---

## 关键参数

| 参数 | 建议值 | 说明 |
|------|:---:|------|
| 置信水平 1-α | 0.90-0.99 | 机会约束 α 通常取 0.05 或 0.10 |
| 样本数（SAA） | 500-2000 | 样本越多越精确，但求解更慢 |
| 场景数 | 10-100 | 场景树的分支数 |

## 注意事项

- **分布假设必须有依据**：不能凭空假设正态分布，需从数据检验（QQ 图、KS 检验）
- **期望值模型 ≠ 随机规划**：期望值模型忽略了方差，可能产出高风险解
- **机会约束等价转化**：仅在特定分布（正态、均匀）下才有简洁的确定性等价形式
- **SAA 的样本量**：需平衡精度和计算量，建议做样本量敏感性分析
