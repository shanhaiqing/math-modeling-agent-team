# 01 线性规划（LP）

> 优化方法卡片。Agent 1 阶段 3 算法选择时查阅。

---

## 概述

线性规划是最基本的优化问题类型，目标函数和所有约束条件均为决策变量的线性函数，决策变量为连续型。

**标准形式**：
```
min  c^T x
s.t. Ax ≤ b
     x ≥ 0
```

**对偶形式**：
```
max  b^T y
s.t. A^T y ≤ c
     y ≥ 0
```

---

## 适用场景

| 特征 | 判断条件 |
|------|---------|
| 变量类型 | 全部连续 |
| 目标函数 | 线性（无 x²、x·y、sin(x) 等项） |
| 约束条件 | 全部线性等式/不等式 |
| 典型场景 | 资源分配、生产计划、运输问题、投资组合（简化） |

---

## 求解方法

| 方法 | 复杂度 | 适用规模 | 特点 |
|------|--------|:---:|------|
| 单纯形法 | 指数最坏，多项式平均 | 小-中 | 经典算法，适合热启动 |
| 内点法 | 多项式 | 中-大 | 大规模稀疏问题首选 |
| 对偶单纯形法 | 同单纯形 | 小-中 | 适合约束变化后重新求解 |
| 网络单纯形法 | 多项式 | 大 | 网络流问题专用，极快 |

## 对偶理论要点

- **弱对偶性**：任意可行解的目标值 ≤ 对偶问题目标值（最小化原问题）
- **强对偶性**：若原问题有最优解，则对偶问题也有最优解，且最优值相等
- **互补松弛性**：原变量 × 对偶松弛 = 0，对偶变量 × 原始松弛 = 0
- **影子价格**：对偶变量 y_i 的经济含义 = 第 i 个约束右端项增加 1 单位，目标值改善量

---

## 灵敏度分析

| 分析项 | 方法 |
|--------|------|
| 目标系数 c_j 变化 | 在最优基不变范围内，最优解不变 |
| 右端项 b_i 变化 | 影子价格 × Δb_i = 目标值变化量 |
| 新增约束 | 检查当前最优解是否满足新约束 |
| 新增变量 | 计算 reduced cost，若 <0 则引入可改善目标 |

---

## 注意事项

- LP 假设所有变量连续，若实际含整数变量 → 用 IP/MIP 卡片
- 灵敏度分析仅在最优基不变范围内有效，超出范围需重新求解
- 对偶变量（影子价格）仅在约束为紧时有效
- 退化（多个基相同最优值）可能导致单纯形法循环，但现代求解器已处理
