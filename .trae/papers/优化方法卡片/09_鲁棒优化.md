# 09 鲁棒优化

> 优化方法卡片。Agent 1 阶段 3 算法选择时查阅。条件触发：特征指纹 `uncertainty = "robust"`。

---

## 概述

鲁棒优化在最坏情况下优化，不需要随机参数的分布假设，仅需不确定集（参数的可能取值范围）。适用于参数不确定但分布未知（或不可靠）的场景。

**与随机规划的区别**：随机规划需分布假设，优化期望表现；鲁棒优化不需分布，优化最坏情况表现。

---

## 适用场景

| 特征 | 判断条件 |
|------|---------|
| 参数不确定性 | 参数在某个范围（不确定集）内变化，分布未知 |
| 风险态度 | 风险厌恶，需保证最坏情况下可行 |
| 典型场景 | 供应链（需求波动）、投资组合（最坏收益）、工程（参数容差） |

---

## 不确定集类型

| 类型 | 数学描述 | 保守度 | 适用 |
|------|---------|:---:|------|
| **盒式（Box）** | |ξᵢ - ξ̄ᵢ| ≤ ρ | 极高 | 参数独立变化 |
| **椭球（Ellipsoidal）** | (ξ - ξ̄)^T Σ⁻¹ (ξ - ξ̄) ≤ ρ² | 中 | 参数相关，Σ 已知 |
| **多面体（Polyhedral）** | Σ |ξᵢ - ξ̄ᵢ|/σᵢ ≤ Γ | 中 | 最常用 |
| **Budget of Uncertainty** | Σ |ξᵢ - ξ̄ᵢ|/σᵢ ≤ Γ, |ξᵢ - ξ̄ᵢ| ≤ 1 | 可调 | **推荐** |

---

## Budget of Uncertainty（Bertsimas-Sim 模型）

**最推荐**的鲁棒优化方法，保守度可调。

```
不确定参数: aᵢ ∈ [āᵢ - âᵢ, āᵢ + âᵢ]
鲁棒约束: Σ aᵢ xᵢ ≤ b

等价于:
  Σ āᵢ xᵢ + max_{S⊆{1..n},|S|≤Γ} Σ_{i∈S} âᵢ |xᵢ| ≤ b

引入辅助变量后可转为 MIP:
  Σ āᵢ xᵢ + Γ·z + Σ pᵢ ≤ b
  z + pᵢ ≥ âᵢ·yᵢ, -yᵢ ≤ xᵢ ≤ yᵢ
  z ≥ 0, pᵢ ≥ 0, yᵢ ≥ 0
```

**Γ 的含义**：最多 Γ 个参数同时取最坏值。Γ=0 → 确定性；Γ=n → 最坏情况（盒式）。

---

## 求解方法

| 方法 | 适用 | 说明 |
|------|------|------|
| **鲁棒对等（Robust Counterpart）** | 标准不确定集 | 数学推导 → 确定性 MIP/LP |
| **Γ 参数扫描** | Budget of Uncertainty | 不同 Γ 值求解 → 保守度-目标值 trade-off |
| **列生成** | 大规模 | 迭代添加最坏场景 |

---

## 关键参数

| 参数 | 建议值 | 说明 |
|------|:---:|------|
| 不确定集类型 | Budget of Uncertainty | 首选，保守度可调 |
| Γ | 0, 1, 2, ..., n 扫描 | 关键：展示保守度-目标值 trade-off |
| 参数波动范围 âᵢ | 从数据估计（标准差/经验范围） | 不能凭空设定 |

## 注意事项

- **保守度 trade-off 必须展示**：不同 Γ 值下的目标值变化是论文亮点
- **不确定集的构建依据**：âᵢ 的来源必须是数据（标准差/历史波动），不能主观
- **鲁棒 vs 随机**：选择鲁棒优化必须说明"为什么不用随机规划"（分布未知/不可靠）
- **鲁棒对等推导**：必须写清楚数学推导过程，不能直接给等价形式
