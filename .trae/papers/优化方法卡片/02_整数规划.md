# 02 整数规划（IP / MIP）

> 优化方法卡片。Agent 1 阶段 3 算法选择时查阅。

---

## 概述

整数规划要求部分或全部决策变量取整数值。纯整数规划（IP）全部变量为整数，混合整数规划（MIP）部分变量为整数。是 CUMCM B 题最常见的问题类型。

**标准形式（MIP）**：
```
min  c^T x + d^T y
s.t. Ax + By ≤ b
     x ∈ Z^n (整数), y ∈ R^m (连续), x ≥ 0, y ≥ 0
```

---

## 适用场景

| 特征 | 判断条件 |
|------|---------|
| 变量类型 | 含 0-1 变量 / 整数变量 / 混合 |
| 典型场景 | 选址、指派、调度、背包、路径、网络设计 |
| 不可用连续近似 | 0-1 变量不能近似为 [0,1] 连续（如"建/不建"） |

---

## 求解方法

| 方法 | 原理 | 适用规模 | 最优性 |
|------|------|:---:|:---:|
| **分支定界（B&B）** | 分解为 LP 子问题，剪枝 | 小-中 | 保证最优 |
| **割平面法** | 添加 Gomory 割排除非整数解 | 小-中 | 保证最优 |
| **分支切割（B&C）** | B&B + 割平面 | 中-大 | 保证最优 |
| **分支定价（B&P）** | B&B + 列生成 | 大（特殊结构） | 保证最优 |
| **Benders 分解** | 主问题-子问题迭代 | 大（阶段结构） | 保证最优 |
| **拉格朗日松弛** | 放松难约束，求下界 | 大 | 下界保证 |
| **启发式** | 贪心/局部搜索/元启发式 | 大 | 无保证 |

## 关键参数

| 参数 | 建议值 | 说明 |
|------|:---:|------|
| 求解器 | solver_backend.py（HiGHS/CBC） | 开源无需 license，统一经 `code_templates/solver_backend.py` 调用 |
| MIPGap | 0.01（1%） | 最优性间隙阈值，≤5% 可接受 |
| TimeLimit | 3600（秒） | 时间上限，超时返回当前最优 |
| Threads | 8（或 CPU 核数） | 并行线程数 |

---

## 建模技巧

| 技巧 | 方法 | 示例 |
|------|------|------|
| **大 M 法** | 用大常数 M 建立条件约束 | x ≤ M·y（y∈{0,1}时，y=0→x=0） |
| **逻辑约束** | OR / AND / XOR / IMPLIES | y₁ + y₂ ≤ 1（互斥） |
| **SOS 约束** | Special Ordered Set | SOS1：至多一个非零；SOS2：至多两个相邻非零 |
| **对称性破缺** | 添加约束打破对称 | y₁ ≤ y₂ ≤ ... ≤ yₙ（强制排序） |
| **紧上界** | 用最小可能 M 值 | M = min(容量, 需求) 而非 M = 10⁹ |

**M 值选择原则**：M 取满足约束的最小值，过大导致 LP 松弛弱、求解慢。

## 注意事项

- **M 值陷阱**：过大 M 值导致 LP 松弛极弱，求解极慢。M 应取"足够大但尽量小"的值
- **对称性**：0-1 变量对称会导致 B&B 树爆炸，需添加破缺约束
- **LP 松弛**：验证 LP 松弛的界是否紧？若不紧，考虑添加 valid inequalities
- **MIPGap vs TimeLimit**：两者同时设置，以先达到者为准
- **不可行 → 找 IIS**：若模型不可行，用 `computeIIS()` 找最小矛盾约束集
