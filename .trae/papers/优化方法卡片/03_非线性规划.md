# 03 非线性规划（NLP）

> 优化方法卡片。Agent 1 阶段 3 算法选择时查阅。

---

## 概述

非线性规划的目标函数或约束条件中至少有一个是决策变量的非线性函数。按凸性分为凸 NLP（全局最优可保证）和非凸 NLP（仅保证局部最优）。

---

## 适用场景

| 特征 | 判断条件 |
|------|---------|
| 目标函数 | 含 x²、e^x、log(x)、sin(x)、x·y 等非线性项 |
| 约束条件 | 含非线性等式/不等式 |
| 典型场景 | 参数估计（最小二乘）、投资组合（均值-方差）、排队优化、几何设计 |

---

## 凸性判断

| 条件 | 判断方法 |
|------|---------|
| 凸函数 | Hessian 矩阵半正定 ∇²f(x) ⪰ 0 |
| 凸约束 | 可行域 {x | g(x) ≤ 0, h(x) = 0} 为凸集 |
| 充分条件 | 线性约束 + 凸目标 → 凸 NLP |
| 仿射等式 | h(x) = Ax - b = 0 保持凸性 |

**凸 NLP 局部最优 = 全局最优**。非凸 NLP 需多起点或全局优化方法。

---

## 求解方法

| 方法 | 适用 | 收敛性 | 特点 |
|------|------|:---:|------|
| **梯度下降** | 无约束 NLP | 线性 | 简单，步长需调参 |
| **牛顿法** | 无约束/等式约束 | 二次 | 需 Hessian，计算量大 |
| **拟牛顿法（BFGS）** | 无约束 | 超线性 | 不需 Hessian，实用 |
| **共轭梯度** | 大规模无约束 | 线性 | 内存友好 |
| **内点法（IPOPT）** | 约束 NLP | 超线性 | 大规模首选 |
| **SQP（序列二次规划）** | 中小规模约束 NLP | 超线性 | 精确但每步代价高 |
| **增广拉格朗日** | 等式约束 | 线性 | 适合等式约束多 |
| **多起点局部搜索** | 非凸 NLP | — | 从多个初始点出发，取最优 |
| **全局优化** | 非凸 NLP | — | 分支定界 + 凸松弛 |

---

## 关键参数（IPOPT）

| 参数 | 建议值 | 说明 |
|------|:---:|------|
| tol | 1e-8 | 收敛容忍度 |
| max_iter | 3000 | 最大迭代次数 |
| acceptable_tol | 1e-6 | 可接受容忍度 |
| linear_solver | mumps / ma57 | 线性求解器选择 |

## KKT 最优性条件

对于 NLP：
```
min  f(x)
s.t. g(x) ≤ 0, h(x) = 0
```

KKT 条件（一阶必要条件）：
1. **稳定性**：∇f(x) + Σ λ_i ∇g_i(x) + Σ μ_j ∇h_j(x) = 0
2. **原始可行性**：g(x) ≤ 0, h(x) = 0
3. **对偶可行性**：λ ≥ 0
4. **互补松弛**：λ_i · g_i(x) = 0

**充分条件**：若 f 凸、g 凸、h 仿射，KKT 也是充分条件。

## 注意事项

- **凸性验证**：求解前必须验证凸性，非凸 NLP 的局部最优 ≠ 全局最优
- **初始点敏感**：非凸 NLP 结果取决于初始点，必须多起点验证
- **梯度计算**：若手动提供梯度，必须验证正确性（有限差分检查）
- **约束违反**：检查最优解处约束满足情况（g(x) ≤ tol）
- **IPOPT 返回状态**：`Solve_Succeeded` 才可信，`Infeasible` 检查约束是否矛盾
