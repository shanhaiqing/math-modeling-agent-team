# 06 图论与网络优化

> 优化方法卡片。Agent 1 阶段 3 算法选择时查阅。

---

## 概述

图论与网络优化研究图（节点 + 边）上的最优化问题，涵盖路径、流、匹配、生成树等经典问题。在 CUMCM B 题中常见于物流、交通、通信网络等场景。

---

## 适用场景

| 特征 | 判断条件 |
|------|---------|
| 节点 | 实体（城市/仓库/路由器/任务） |
| 边 | 实体间关系（道路/管道/连线/依赖） |
| 边权 | 距离/时间/成本/容量 |
| 典型场景 | 最短路径、最大流、最小生成树、网络设计、车辆路径 |

---

## 经典问题与算法

| 问题 | 算法 | 复杂度 | 说明 |
|------|------|--------|------|
| **最短路径（单源）** | Dijkstra | O((V+E)logV) | 非负权边 |
| **最短路径（单源）** | Bellman-Ford | O(VE) | 可处理负权 |
| **最短路径（全源）** | Floyd-Warshall | O(V³) | 稠密图 |
| **最大流** | Dinic | O(V²E) | 最常用 |
| **最大流** | Edmonds-Karp | O(VE²) | 学习用 |
| **最小费用流** | Successive Shortest Path | O(F·ElogV) | F=流量 |
| **最小生成树** | Prim | O(ElogV) | 稠密图 |
| **最小生成树** | Kruskal | O(ElogE) | 稀疏图 |
| **二分图匹配** | Hungarian | O(V³) | 最大权匹配 |
| **TSP** | 分支定界 + 启发式 | — | NP-hard |

## 建模技巧

### 网络流建模

| 场景 | 建模方式 |
|------|---------|
| 供需平衡 | 源点 → 供应节点（容量 = 供应量），需求节点 → 汇点（容量 = 需求量） |
| 节点容量 | 拆点为入点和出点，中间连边（容量 = 节点容量） |
| 多商品流 | 每种商品独立流量，共用边容量总和受限 |
| 最小费用 | 边权 = 单位流量费用，目标 = 最小化总费用 |

### 图论建模

| 场景 | 建模方式 |
|------|---------|
| 覆盖问题 | 顶点覆盖 / 边覆盖 / 集合覆盖 |
| 连通性 | 最小生成树 + 度数约束 |
| 可靠性 | 最小割 = 最大流（最大流最小割定理） |
| 聚类 | 最小割 / 谱聚类 |

## 关键参数

| 参数 | 建议值 | 说明 |
|------|:---:|------|
| 图规模 V | ≤ 10⁴（精确算法） | 超大规模 → 启发式 |
| 图规模 E | ≤ 10⁵（精确算法） | 稀疏图优选邻接表 |
| 求解器 | NetworkX + solver_backend.py（HiGHS/CBC） | 小规模用 NetworkX，大规模用统一求解后端 |

## 注意事项

- **Dijkstra 不能处理负权边**，有负权用 Bellman-Ford 或 SPFA
- **最大流最小割定理**：最大流值 = 最小割容量，可用于敏感性分析
- **TSP 是 NP-hard**：V > 20 时精确算法不可行，需启发式（最近邻 + 2-opt）
- **网络流建模的艺术**：拆点、加虚源/汇、容量设置是常见技巧
