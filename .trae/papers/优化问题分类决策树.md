# 优化问题分类决策树（B 题）

> v1.2 (2026-08-26)：modeling-solver 阶段 1 使用。通过 5 个问题逐步定位优化问题大类，输出 problem_type 字段。

---

## 决策树

```
开始
  │
  ▼
Q1: 目标数量？（前置判定——多目标直接改变求解范式：权重法/ε-约束/NSGA-II）
  ├── 多目标（≥2 个冲突目标）──────→ MOO（多目标优化）
  └── 单目标 ─────────────────────→ Q2
      │
      ▼
Q2: 是否存在时间维度（多阶段决策且阶段间有递推关系）？
  ├── 是，且具有最优子结构 ────────→ DP（动态规划）
  └── 否（单阶段/静态，或阶段耦合复杂）→ Q3
      │
      ▼
Q3: 决策变量是否包含离散/整数变量？
  ├── 否（全部连续）──────────────→ Q4
  └── 是（含 0-1/整数/混合）─────→ Q5
      │
      ▼
Q4: 目标函数和约束是否全部线性？
  ├── 是（全部线性）──────────────→ LP（线性规划）
  └── 否（含非线性）──────────────→ Q4a
      │
      ▼
  Q4a: 目标函数是否可微？可行域是否凸？
    ├── 是（凸优化）──────────────→ NLP_Convex（凸非线性规划）
    └── 否（非凸）───────────────→ NLP_Nonconvex（非凸非线性规划）
      │
      ▼
Q5: 问题是否具有网络/图结构？
  ├── 是（节点+边+流）───────────→ Network（网络优化）
  └── 否 ────────────────────────→ Q5a
      │
      ▼
  Q5a: 组合结构是否显著（排列/子集选择/匹配，宜用专用组合算法而非通用 MIP 求解器）？
    ├── 是 ──────────────────────→ Combinatorial（组合优化，经典模式库 01/02/03/06）
    └── 否 ──────────────────────→ Q5b
        │
        ▼
    Q5b: 变量是全整数还是混合？
      ├── 全整数 ────────────────→ IP（整数规划）
      └── 混合整数 ──────────────→ MIP（混合整数规划）
```

## 各类型特征速查

| 类型 | 变量 | 目标 | 约束 | 典型求解方法 |
|------|------|------|------|------------|
| LP | 连续 | 线性 | 线性 | 单纯形法、内点法 |
| IP | 整数 | 线性 | 线性 | 分支定界、割平面 |
| MIP | 混合 | 线性 | 线性 | 分支定界、Benders 分解 |
| NLP_Convex | 连续 | 凸 | 凸 | 梯度下降、内点法 |
| NLP_Nonconvex | 连续 | 非凸 | 非凸 | 多起点局部搜索、启发式 |
| MOO | 连续/离散 | 多目标 | 线性/非线性 | 权重法、ε-约束、NSGA-II |
| DP | 离散/连续 | 可加性 | 阶段递推 | 值迭代、策略迭代 |
| Network | 连续/离散 | 线性/非线性 | 流守恒+容量 | 网络单纯形、最大流算法 |
| Queueing | 连续/离散 | 非线性 | 稳态+服务等级 | 解析解、非线性规划、仿真优化 |

## 边界情况处理

| 情况 | 处理 |
|------|------|
| 含随机参数 | 在基本类型后标注 Stochastic（如 LP_Stochastic） |
| 含不确定参数且需鲁棒解 | 标注 Robust（如 MIP_Robust） |
| 排队论特征 | 标注 Queueing，见经典模式库模式 09 |
| 博弈/竞价特征 | 标注 Game，见经典模式库模式 10 |
| 无法明确归类 | 标注 Other，走第一性原理建模 |

## 输出映射表（决策树输出 → feature_fingerprint 字段）

> 决策树的细分类型须降维映射回指纹模板枚举，细分语义由其他字段承载（总审批清单 D-3）。

| 决策树输出 | problem_type 取值 | 其他 fingerprint 字段 |
|---|---|---|
| NLP_Convex / NLP_Nonconvex | NLP | objective_type = nonlinear_convex / nonlinear_nonconvex |
| LP_Stochastic（含随机参数） | LP | uncertainty = stochastic（Robust / Fuzzy 同法映射） |
| MIP_Robust（含不确定参数需鲁棒解） | MIP | uncertainty = robust |
| Queueing / Game（边界标注） | Queueing / Game | —— |
| Other | Other | —— |

## 使用示例

```
题目：确定 n 个候选仓库中选 p 个，使总运输成本最小

Q1: 多目标？→ 否（单目标：最小化成本）
Q2: 多阶段递推？→ 否
Q3: 含离散变量？→ 是（选址变量 y_j ∈ {0,1}）
Q5: 网络结构？→ 否
Q5a: 组合结构显著？→ 否（通用 MIP 即可）
Q5b: 全整数还是混合？→ 混合（选址变量整数，分配变量连续）

→ problem_type: MIP（混合整数规划）
→ 经典模式匹配：模式 05（选址问题）
```
