# 01 数据预处理与清洗

> 数据方法卡片。Agent 1 阶段 1-2 使用；一切后续建模的前置工序。

---

## 概述

原始数据到可建模数据的转换层。任何模型结论的可信度不超过预处理的可信度。

**标准流程**：
```
原始数据 → 结构核验（行列/类型/主键）→ 缺失处理 → 异常处理
        → 编码（类别变量）→ 缩放（量纲）→ 派生特征 → 可建模数据集
```

---

## 适用场景

| 特征 | 判断条件 |
|------|---------|
| 触发时机 | 所有数据题必经；大附件题先按"大附件处理规范"输出摘要再进入本卡片 |
| 输入 | 附件原始表（csv/xlsx）或自搜集数据 |
| 输出 | 可建模数据表 + preprocessing 记录（写 solution.json） |

---

## 处理方法

| 问题 | 候选方法 | 选择判据 |
|------|---------|---------|
| 缺失值 | 删除 / 均值中位数填补 / 模型填补 / 哑变量标记 | 缺失率 <5% 可删；5-30% 填补+标记；>30% 论证变量去留 |
| 异常值 | ±3σ / IQR(1.5×) / 分位数截断 / 保留并标记 | 先判"错误值 vs 真实极端值"，错误值剔除，真实极端值截断或保留 |
| 类别编码 | One-Hot / 序号编码 / 目标编码 | 无序低基数→One-Hot；有序→序号；高基数→目标编码（防泄漏需折内计算） |
| 缩放 | 标准化(z-score) / 归一化(min-max) / 不缩放 | 距离类/正则化模型必缩放；树模型可不缩放 |
| 不平衡 | 过采样(SMOTE) / 欠采样 / 类别权重 | 少数类 <10% 时必处理 |

---

## 关键参数

| 参数 | 建议值 | 说明 |
|------|:---:|------|
| 缺失率阈值 | 5% / 30% | 决定删除或填补策略 |
| 异常判定 | ±3σ 或 IQR×1.5 | 与探索卡片 02 的分布结论联动 |
| 随机种子 | 固定并记录 | 采样/SMOTE/划分全部定种子 |

---

## 防泄漏铁律（本卡片最高优先级）

- **所有预处理统计量（均值/方差/编码映射/特征选择）必须只在训练集上拟合**，再应用到验证/测试集
- 时间序列禁止随机划分，须按时间先后切分（滚动原点）
- 目标编码、SMOTE 仅在训练折内执行
- `preprocessing.train_test_isolation` 字段必须显式声明隔离方式

---

## 注意事项

- 每一步处理记录"处理前 → 处理后 → 理由"，写入 solution.json 的 preprocessing 字段，论文按数据题专项惯例 数.2 透明报告
- 删除样本须报告删除数量与占比；截断须报告触发次数（惯例 二.35）
- 派生特征须注明业务含义与构造公式
- 预处理方案须与 data_quality 结论呼应（缺失/异常结论来自实测，禁止凭印象）
