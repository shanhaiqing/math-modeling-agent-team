# reference-studio — 数模论文参考文献工作室

> 定位：不是格式规范说明，而是**参考文献全生命周期核验工作流**。补上"可查证"要求的机器核验缺口——惯例 二.3 长期只有要求、无核查者。
> 配套资产：合规判据见 `.trae/papers/国赛公开惯例.md` 一.22（检索来源管理核查）/ 二.3（参考文献可查证）；格式规范见 `.trae/papers/LaTeX格式规范.md`（GB/T 7714、`\cite{}`）；核验脚本见 `scripts/`。

## 通道规则（先选通道，再动手）

| 任务性质 | 通道 | 工具 |
|---|---|---|
| 写作时插入新引用 | 引用通道 | WebSearch/WebFetch 查证（DOI 或出版社页面）→ GB/T 7714 格式化 → `\cite{}` |
| 正文↔文献列表核对 | 对账通道 | `scripts/citation_check.py`（双向核对 + 括注来源提点） |
| 可查证性验证（交付前/评审/校准） | 审计通道 | `scripts/doi_audit.py`（DOI/URL 可达性批量核验） |

**禁止**：引用查无出处的文献（无 DOI 且无出版社页面的灰色来源）；正文括注来源不入文献列表（惯例 一.22b）；列表堆正文未引的僵尸文献凑数。

## 工作流（5 步；步骤 0 在写作初期，2-3 在初稿后，可循环）

0. **拟引预筛查**（写作初期）：将拟引文献的 DOI/URL 逐行写入临时清单，`python scripts/doi_audit.py precheck <清单>` 批量验可达性——死链在写作前淘汰，通过率 <90% → 换来源，不要等到交付前才发现。
1. **引用插入**（引用通道）：每条新文献先确认 DOI 或出版社页面可达（惯例 二.3），按 GB/T 7714 写入 thebibliography/.bib，正文 `\cite{key}` 标注；发表年份 ≤ 赛题发布年份（惯例 一.22a，机查 check_reference_years 兜底，本工作室不重复检查）。
2. **双向核对**（对账通道）：`python scripts/citation_check.py <paper.tex>`（**`shuwei_en` 加 `--contest-profile=shuwei_en`**）——正文引用但列表缺失（幽灵引用）→ ERROR；列表存在但正文未引（僵尸文献）→ WARN；正文中文括注含年份但无 `\cite`（疑似括注来源未入列，惯例 一.22b）→ WARN 提点人工逐条核对。**`shuwei_en`**：纯西文 `(Author, 2023)` 不提点；括注内含汉字仍提点。
3. **可达性审计**（审计通道）：`python scripts/doi_audit.py scan <paper.tex或.bib>`——全部文献的 DOI/URL 批量请求：确定不可达（404/410/域名不存在）→ ERROR；超时/连接失败 → WARN（网络环境存疑，人工裁定）；条目无 DOI/URL → WARN（无法机查，人工核对）。
4. **修复闭环**：死链文献换等价来源（年份仍须 ≤ 赛题年份）；幽灵引用补列表条目或删正文引用；僵尸文献删除或正文补引。修复后重跑步骤 2-3 直至 ERROR 清零。

## 红线（不可协商）

- **可查证**：每条参考文献必须可通过 DOI 或出版社页面访问（惯例 二.3；AGENTS.md 合规检查硬项）。
- **年份合规**：若引用外部来源或参考文献，发表年份 ≤ 赛题发布年份（惯例 一.22a）。
- **双向一致**：无幽灵引用、无僵尸文献、正文括注来源全量入列（惯例 一.22b）。
- **禁编造**：找不到可查证来源的论断不得配伪引用——宁可删除该论断。
- **数量下限**：≥10 篇由机查 check_bibliography 覆盖，本工作室不重复检查（维度去重）。
