# 方法学闸门（stats）

只答下面四条。每条须有题面、`modeling_plan.json`、`solution.json` 或代码中的证据。不要把 MIP、活跃约束或最优间隙套到本轨。

1. 各子问的 `task_type` 和指纹，是否与题面要的输出同构？
2. 划分和预处理是否对准数据结构？时序或分组数据若被随机切开，或泄漏步骤没有隔离实现，即属错配。
3. 主模型是否被更简单的基线，或已经试过又放弃的候选支配？指标是否与任务匹配？
4. 验证检验的是训练折外的泛化，还是只证明训练集拟合得好？

四条都不构成错配，闸门通过。任务类型错了，或泄漏会造成虚高的性能，`verdict=BLOCKED`。换成更复杂的模型但不改变结论形态，最多出升级票，不得因此 BLOCKED。
