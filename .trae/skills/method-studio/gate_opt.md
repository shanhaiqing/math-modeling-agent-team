# 方法学闸门（opt）

只答下面四条。每条须有题面、`modeling_plan.json`、`solution.json` 或代码中的证据。不要改用统计轨的问法。

1. 问题的数学结构与 `feature_fingerprint.json` 是否同构？
2. 决策变量、目标、约束是否对准题面真正该控的量？
3. 主方法是否被更简单、且代码或计划里已经试过的做法支配？小规模可精确求解却主上元启发式，即属错配。
4. 验证检验的是模型本身，还是只证明求解器把当前模型求完了？

四条都不构成错配，闸门通过。任一条构成错配，或换方法会改变策略集或最优解类型，`verdict=BLOCKED`。只说「可以更深入」而没有替代方法名，不得交付。
