**C 系统 HG0 判据原文要点**：数据驱动/统计/机器学习类 → 完整路径；纯机理推演类（无数据或数据仅作验证）/ 无数据纯优化类 → fallback 通用路径（决策树 Other + 第一性原理建模 + WebSearch，知识库覆盖度降一级）；不得直接终止流水线。

## 3. 执行方式：全量双判定

- 每道题**独立执行两次判定**：B 系统 HG0 判定 + C 系统 HG0 判定，互不短路。
- 判定输入为题目原文（统一文本格式）；**不得**用既往演练日志代替题目原文作判定输入。
- 判定必须**忠实于现行判据**，逐条对照并记录命中/未命中的判据节点（判据轨迹）；判定中发现的判据缺陷只记录、不修改（防过拟合）。

## 4. 判读标准（三档 + 子问级映射）

| 判定结果 | 定义 | 实验标记 |
|---------|------|---------|
| 主干覆盖（强） | 该系统 HG0 判定为题型的**主干路径**（B=优化/运筹；C=数据驱动/统计/ML） | 强覆盖 |
| fallback 覆盖（弱） | 该系统 HG0 判定为 **fallback 通用路径**（知识库覆盖度降一级） | 弱覆盖 |
| 转场提示 | B 系统 2026-08-C3 条款触发（建议转 C 系统执行） | 弱覆盖（带转场提示） |

- **年度分级**：任一系统强覆盖 → 该年度有主干承接；两系统均仅弱覆盖 → **真缺口**。
- **混合题**（判据中的"含优化成分混合/多任务复合"）：追加**子问级映射表**（每个子问 → 最优承接系统 + 知识卡片/方法），标题级判定允许"主干+子问缺口"标记。

## 5. 判定卡格式（每题一个文件）

1. 题目摘要（子问列表）
2. B 系统判定轨迹：判据命中点（引用条款原文）→ 决策树路径 → 结论（强/弱/转场）
3. C 系统判定轨迹：同上
4. 子问级映射表（混合题必填，纯主干题可简）
5. 年度分级结论
6. 与历史演练 HG0 判定对照（若存在独立 HG0 记录；仅作对照列，不参与判定）
7. 判据缺陷记录（判定过程中发现的判据表述歧义/缺失，供后续规则提案参考）
