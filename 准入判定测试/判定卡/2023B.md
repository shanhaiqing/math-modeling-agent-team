## 1. 题目摘要（子问）

1. 与测线垂直平面内覆盖宽度与重叠率的数学模型（坡面解析几何 + 给定 9 个位置计算）
2. 测线方向与海底坡面法向投影夹角 β 下的覆盖宽度模型（三维几何 + 8×8=64 格计算）
3. 2×4 海里矩形海域测线设计：总长度最短 + 完全覆盖 + 重叠率 10%~20%（几何优化）
4. 基于附件实测水深数据（单波束测深网格）的多波束测线布置：覆盖最大 + 重叠率 ≤20% + 总长最短（数据驱动的几何优化，三目标）

## 2. B 系统判定轨迹

- **HG0 条款对照**：问 3/问 4 为核心优化任务（决策变量=测线间距/方向/位置，目标=总长最短/覆盖最大，约束=重叠率区间+全覆盖）→ 命中"**含优化成分的混合题按优化类主干走完整路径**"；问 1/问 2 属非优化部分（解析几何推导），按判据"非优化部分在建模阶段按 fallback 原则补充"。
- **决策树路径（针对优化部分）**：
  - Q1 目标数量 → 问 4 三目标（覆盖/重叠率/总长）→ 可标 **MOO** 或加权单目标化；问 3 单目标（总长最短）
  - Q2 时间递推 → 否（静态空间布局）
  - Q3 离散变量 → 是（测线位置/间距离散化网格）→ Q5 网络结构 → 否 → Q5a 组合结构 → 不显著 → Q5b 混合 → **MIP**（或几何 NLP：连续化建模 → NLP_Convex/Nonconvex）
- **结论**：**强覆盖**（几何优化主干：NLP/MIP/MOO + 启发式；问 1/2 几何推导按 fallback 补充——几何解析部分无专属卡片）。
