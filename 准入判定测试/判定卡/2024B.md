# 判定卡 2024B — 生产过程中的决策问题

> 判定日期：2026-08-31 ｜ 判定主体：主智能体 ｜ 判定输入：`题目文本/2024B.txt`（PDF 提取，完整；无外部附件，参数在题面表格）

## 1. 题目摘要（子问）

1. 抽样检测方案设计：次品率标称值 10% 下，检测次数最少的方案（95% 拒收 / 90% 接收两种信度）（统计推断：假设检验 + 样本量设计）
2. 各阶段决策：零配件是否检测 / 成品是否检测 / 不合格品是否拆解 / 调换处理（六种情形）（期望利润最大化决策）
3. m 道工序 n 个零配件的一般化决策方案（2 工序 8 零件实例）（组合决策优化）
4. 次品率由问题 1 抽样估计得到，重做问题 2/3（估计 + 决策的耦合）

## 2. B 系统判定轨迹

- **HG0 条款对照**：问 2/3/4 主体为"决策变量（检测/不检测、拆解/不拆解 0-1）+ 目标（期望利润最大化）+ 约束"→ 命中"**含优化成分的混合题按优化类主干走完整路径**"；问 1（抽样检验）属统计部分，按判据"非优化部分按 fallback 原则补充"。
- **决策树路径（优化部分）**：
  - Q1 目标数量 → 单目标（期望利润最大）
  - Q2 时间/阶段递推 → 问 3 多工序呈阶段结构（半成品→成品）→ 可标 **DP**（决策树/期望值递推）
  - Q3 离散变量 → 是（0-1 检测/拆解决策）→ Q5 网络结构 → 否（非流网络）→ Q5a 组合结构 → 一般 → Q5b 混合/整数 → **MIP**（含概率参数 → 边界标注 Stochastic）
- **结论**：**强覆盖**（DP/MIP_Stochastic + 期望值建模；方法卡片 02/05/08/10 在射程内）。

## 3. C 系统判定轨迹

- **HG0 条款对照**：问 1 为典型统计推断（假设检验/样本量设计），问 2-4 为"基于概率参数的决策分析"——整体命中"**数据驱动/统计类 → 走本流水线完整路径**"（题面概率参数与抽样机制构成统计决策主体）。
- **决策树路径**：
  - 问 1：Q1 有目标（次品率是否超标的判定）→ Q2b 客观规则可定义 → **Inference（统计推断，卡片 09）**
  - 问 2/3：Q4 结论需衔接下游决策 → `_Downstream`（**卡片 12 数据+优化衔接**：期望利润计算 + 决策树权衡）
  - 问 4：估计 + 决策耦合 → Inference + `_Downstream`
  - Q5 样本量：题给概率参数 + 自设抽样 → SmallSample/参数设定混合，按卡片 09/10 处理
- **结论**：**强覆盖**（Inference + `_Downstream`），但优化决策求解依赖卡片 12 的知识层，C 系统无现成优化求解器脚手架（弱项见缺陷 3）。
