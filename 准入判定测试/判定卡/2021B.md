# 判定卡 2021B — 乙醇偶合制备 C4 烯烃

> 判定日期：2026-08-31 ｜ 判定主体：主智能体 ｜ 判定输入：`题目文本/2021B.txt`（PDF 提取，完整；附件 1/2 为实验数据表）

## 1. 题目摘要（子问）

1. 各催化剂组合下转化率/选择性与温度的关系；附件 2 测试数据分析（回归/曲线拟合）
2. 催化剂组合及温度对转化率、选择性大小的影响（影响分析/回归解释）
3. 选择催化剂组合与温度使 C4 烯烃收率尽可能高（含温度 <350℃ 情形）（寻优）
4. 允许再增加 5 次实验，如何设计并给出理由（实验设计）

## 2. B 系统判定轨迹

- **HG0 条款对照**：题目输入为两张实验数据表（附件 1/2），主体任务为关系建模与影响分析，命中"**数据驱动/统计类 → 走 fallback 通用路径**"；问 3 虽含寻优成分，但按主干"优化成分"标准衡量，仅占 4 问之一，题面主体是统计建模。
- **转场条款**：命中 2026-08-C3 条件（数据驱动/统计类）→ 应向用户提供〖转场姊妹系统执行〗选项。
- **结论**：**弱覆盖**（fallback；若用户选择不转场，则 "决策树 Other + 第一性原理建模 + WebSearch" 硬跑，知识库覆盖度降一级）。
- **判据竞合记录**：HG0 两条款（"数据驱动→fallback" vs "含优化成分混合题→优化主干"）在本题竞合，判据未定义成分权重的量化标准；按"主体成分"口径判定为数据驱动主体。

## 3. C 系统判定轨迹

- **HG0 条款对照**：附件实验数据驱动的关系建模+寻优+实验设计，命中"**数据驱动/统计/机器学习类 → 走本流水线完整路径**"。
- **决策树路径**：
  - 问 1：Q1 有目标变量（转化率/选择性）→ Q2 连续 → Q2a 含时间依赖？→ 附件 1 为温度序列（非时序预测，截面）→ **Regression（卡片 03/05）**；附件 2 为时间序列测试结果（短时序分析）
  - 问 2：影响大小分析 → Regression + **Inference（相关/显著性，卡片 09/11）**
  - 问 3：寻优 → `_Downstream`（**卡片 12 数据+优化衔接**）
  - 问 4：追加实验设计 → **卡片 13 实验设计**
  - Q5 样本量：A1-A14+B1-B7 共 21 组 → **SmallSample** 标注（卡片 09/10 精确法优先）
- **结论**：**强覆盖**（Regression / Inference / `_Downstream` / 实验设计，13 张卡片全覆盖四问）。
