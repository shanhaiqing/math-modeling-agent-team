# 经典模式库（C 题 · 数据驱动问题）

> v1.0 (2026-07-22)：Agent 1 阶段 2 GQ5 参考。按历年 C 题公开题型提炼 10 类数据问题模式，每类提供标准数据流、方法栈与陷阱。**仅含公开题号与题型信息，无任何论文内容**。

---

## 使用说明

- 特征指纹与决策树归类完成后查阅本文档，匹配最接近的模式
- 匹配后标注偏离说明（与标准数据流的差异）；模式匹配不是强制套用
- 每模式的"方法栈"指向数据方法卡片编号，须回读对应卡片

---

## 模式 01：成分/指标分析模式

**典型场景**：给定多对象的多维成分/指标数据（化学组分、光谱、生理指标等），分析成分规律并鉴别类别。例：2022C（玻璃成分分析与鉴别）、2017C（颜色与浓度辨识）。

**标准数据流**：
```
成分矩阵 → 描述统计与可视化（卡片 02）→ 组间差异检验（卡片 09）
→ 降维/特征提取（卡片 07）→ 分类或聚类（卡片 05/06）→ 规律解释
```

**方法栈**：01 → 02 → 09 → 07 → 05/06

**常见变体**：已知类别的鉴别（监督）、未知类别数的分型（无监督）、成分间关联规律挖掘

**典型陷阱**：
- 成分数据闭合性（总和为 1）导致伪相关，直接相关分析失真
- 高维小样本直接上复杂分类器 → 过拟合；先降维或正则
- 差异检验忽略多重比较校正

---

## 模式 02：综合评价与排序模式

**典型场景**：对多对象按多指标综合打分排序/分级/优选。例：2005C（预报方法评价）、2021C 子问题（供应商评价）。

**标准数据流**：
```
指标体系构建（依据陈述）→ 同向化+无量纲化 → 赋权（主观/客观/组合）
→ 集结打分（卡片 08）→ 排序/分级 → 权重扰动稳健性
```

**方法栈**：01 → 08（→ 07 若先降维）

**常见变体**：评价结果作为下游资源分配输入（接模式 03/10）、动态多期评价

**典型陷阱**：
- 指标体系随手罗列无依据
- AHP 不做一致性检验
- 排序结果不做稳健性，权重稍变名次全翻

---

## 模式 03：预测→决策衔接模式

**典型场景**：先由历史数据预测需求/销量/价格，再以预测为输入做定价、补货、生产决策。例：2023C（蔬菜定价与补货）、2014C（生猪养殖经营）。

**标准数据流**：
```
流水/时序数据 → 清洗聚合（卡片 01）→ 规律探索（卡片 02）
→ 时序建模预测（卡片 04/05）→ 预测值+区间传递（卡片 12）
→ 决策模型（定价/补货）→ 输入扰动灵敏度
```

**方法栈**：01 → 02 → 04/05 → 12（→ 08 若含品类评价）

**常见变体**：多品类分别预测再联合决策、含损耗/保质期的决策

**典型陷阱**：
- 只把点预测喂给决策模型，丢弃预测区间（卡片 12 禁区）
- 时间序列随机划分训练/测试（泄漏）
- 决策端不做输入扰动分析

---

## 模式 04：风险评估与授信模式

**典型场景**：基于企业/客户特征评估违约/风险概率，并给出额度、利率、准入决策。例：2020C（中小微企业信贷决策）。

**标准数据流**：
```
特征工程（财务/行为指标，卡片 01）→ 探索（卡片 02）
→ 分类模型估概率（卡片 05）→ 概率校准与阈值
→ 决策规则（额度/利率，卡片 12）→ 阈值扰动分析
```

**方法栈**：01 → 02 → 05 → 10 → 12

**常见变体**：无违约标签时构造代理标签（规则/聚类）、不平衡样本

**典型陷阱**：
- 类别不平衡只报 Accuracy（卡片 05 禁区）
- 重采样在全数据上做再划分（泄漏）
- 阈值凭直觉定，不做成本-收益权衡

---

## 模式 05：用户画像与分群模式

**典型场景**：基于消费/行为流水对客户分群画像，给差异化运营策略。例：2018C（百货商场会员画像）。

**标准数据流**：
```
流水 → 行为特征构造（RFM 类，卡片 01）→ 标准化
→ 聚类定 K（卡片 06）→ 簇画像与命名 → 价值评估（卡片 08，可选）→ 差异化策略
```

**方法栈**：01 → 02 → 06（→ 08）

**常见变体**：生命周期分群、消费偏好关联挖掘

**典型陷阱**：
- 簇只有编号没有画像（卡片 06 强制项缺失）
- 簇数只用一个指标定
- 把聚类当因果：簇间差异≠策略效果

---

## 模式 06：统计关联与干预分析模式

**典型场景**：分析疾病/现象与环境、行为因素的关联，给干预建议。例：2012C（脑卒中环境因素分析）。

**标准数据流**：
```
数据清洗（卡片 01）→ 描述与可视化（卡片 02）
→ 组间比较/相关分析（卡片 09/11）→ 多因素模型（卡片 03/05）
→ 高危人群/关键因素识别 → 干预建议（措辞分级，卡片 11）
```

**方法栈**：01 → 02 → 09 → 11 → 03

**常见变体**：时序上的干预前后对比、倾向得分类平衡

**典型陷阱**：
- 相关写成因果（卡片 11 分级表越界）
- 多重检验不校正，"发现"一堆假关联
- 病例-对照结构直接当队列解释

---

## 模式 07：曲线拟合与参数辨识模式

**典型场景**：给定机理形态未知的响应曲线数据（放电曲线、衰减曲线、浓度-显色关系），拟合参数并外推。例：2016C（电池剩余放电时间）、2017C（浓度辨识）。

**标准数据流**：
```
散点观察选模型族（卡片 02）→ 候选函数拟合（卡片 03）
→ 残差诊断 → 参数置信区间（卡片 10 bootstrap）→ 外推预测+区间
```

**方法栈**：02 → 03 → 10

**常见变体**：分工况分段拟合、含协变量的参数化

**典型陷阱**：
- 高阶多项式硬拟合一切，外推发散
- 只报 R² 不看残差结构
- 外推不给区间

---

## 模式 08：供需匹配与排队决策模式

**典型场景**：供给方与需求方时空分布不均，决策调度/排队策略平衡效率与收益。例：2019C（机场出租车决策）、2008C（地面搜索）。

**标准数据流**：
```
供需数据描述（卡片 02）→ 到达/服务过程刻画（分布拟合，卡片 09）
→ 排队/匹配模型（机理建模）→ 策略仿真评估（蒙特卡洛）
→ 不同情景策略对比
```

**方法栈**：02 → 09 →（机理建模+仿真）→ 12

**常见变体**：多服务台、优先级、时空分区调度

**典型陷阱**：
- 到达过程分布拍脑袋（泊松假设不检验）
- 仿真单次运行当结论（无重复实验设计）
- 只报均值不报波动

---

## 模式 09：多级供应链订购运输模式

**典型场景**：多供应商-多周期订购与转运决策，含评价、预测、优化三层。例：2021C（原材料订购与运输）。

**标准数据流**：
```
供应商历史供货数据 → 供货特征评价（卡片 08）
→ 需求/供能预测（卡片 04/05）→ 订购+转运联合决策（卡片 12 衔接优化）
→ 方案多情景对比
```

**方法栈**：01 → 08 → 04 → 12

**常见变体**：含损耗率/存储约束、多转运中心

**典型陷阱**：
- 评价层与优化层口径断裂（评价得分没进优化目标/约束）
- 预测层不确定性不传优化层
- 转运方案只给一个情景

---

## 模式 10：数据驱动规划策略模式

**典型场景**：有统计数据支撑的中长期规划/种植/生产策略，数据提供参数，优化出方案。例：2024C（农作物种植策略）、2007C（套餐资费）。

**标准数据流**：
```
统计/调查数据 → 参数估计（卡片 03/09，含区间）
→ 情景设定（确定/不确定）→ 规划模型（LP/IP/多目标，卡片 12 接口）
→ 参数扰动下的策略稳健性
```

**方法栈**：01 → 03/09 → 12

**常见变体**：含随机参数的期望/鲁棒规划、多周期滚动

**典型陷阱**：
- 参数点估计直接用，区间被丢弃
- 土地/资源等硬约束漏建
- 策略不给稳健性证据
