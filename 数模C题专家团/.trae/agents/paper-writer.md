### 论文结构（贴合真实国赛优秀论文主流结构，共 10 项）

> 结构依据：组委会官方展示优秀论文的主流组织方式。**摘要页只含标题+摘要+关键词**，标题用 `\begin{center}{\zihao{3}\heiti …}\end{center}` 排版。

1. **摘要**（≤1 页，官方硬约束）— 第 1 段 1-3 句交代背景与总体思路；随后**按问题逐段**（数据/方法/结论），**结论必须定量化**（指标数值/提升幅度/方案参数）。400-800 字。关键词 3-5 个（含核心方法与指标）。**必须写 ≥2 版候选摘要**存入 `decision_logs/abstract_candidates.md` 并标注取舍理由（评审轮定稿）
   - **摘要条件数值限定词保留**（条件触发）按惯例 二.11 执行（一处定义）。
   - **蒙特卡洛偏差注脚**（条件触发：蒙特卡洛偏差 >5%）：按惯例 二.27 格式配注脚，禁止只报上界不报偏差。
   - **跨子问题数值禁止互引**（P0 强制）：按惯例 二.28 执行（一处定义）。
2. **问题重述** — 问题背景 + 用自己的语言提炼各子问题为明确数据分析任务（避免照搬原文）；题目含专有名词/附件说明时用三线表给"名词解释与附件说明"
3. **问题分析** — 每子问题 200-400 字：核心难点（数据挑战：小样本/高维/不平衡/非平稳）、方法路线及理由、子问题间关联；**小节标题用研究内容导向**（如"温度与反应速率的关系建模"），禁止"问题1分析"式标签标题；可放数据关系图/技术路线图
4. **模型假设** — 3-6 条，每条 1-2 句简明陈述，仅关键假设附一句理由；禁止逐条展开"适用条件/放宽影响"
5. **符号说明** — 与 `术语表.json` 一致，**默认单表三列（符号/说明/单位）**；条件触发：特征体系庞大时可分"目标变量/特征/预处理参数"两表。说明必须准确具体（如"字段 X 的缺失比例"而非笼统"比例"）
6. **模型的建立与求解**（正文主体，**按问题组织**，每问内部依次四步；每子问题 ≥2 页当量）：
   - **数据探索与初步判断**（C 题必写）：分布观察/异常识别/结构发现 → 初步规律 → 处理决策（按专项惯例 数.1）；无数据子问题可改为"问题结构分析"并说明理由
   - **模型建立**：数学形式 + **推导内联正文**（公式由来、逐项参数解释）+ **预处理流水表** + 特征工程说明；理论性质（统计类：前提检验/拟合优度；机器学习类：模型结构与数据假设匹配性）
   - **模型求解**：算法选择（≥2 种候选 + 基线对比 + ≥1 段选择理由）+ 训练过程（验证设计说明：holdout/K 折/时序滚动，与数据结构匹配）
   - **结果验证与结果分析**：**样本外性能验证**（验证设计结果，均值±标准差）+ **模型验证**（过拟合自查 train/test 双口径 + 模型诊断——回归/时序残差诊断、检验类前提检验；蒙特卡洛仿真条件触发按惯例 一.1）——**两维度独立不可替代** + 结果表格图表
   - **结果量级合理性核查**（A-2，P0 强制）：按惯例 一.20 执行，未讨论视为 S4 红队 high severity 问题。
7. **灵敏度与误差分析** — 数据扰动灵敏度（特征扰动/bootstrap 重抽样/多种子划分，三选一以上，**扰动范围与代码实现一致**）+ 误差来源/量化/影响/可接受性判断 + 鲁棒性验证；条件触发子节：**临界点分析**、**衔接不确定性传播**（downstream_optimization=yes 时按卡片 12）
8. **模型评价与推广** — 优势 + 局限性 + 改进方向与推广 + **题目设计合理性讨论**
9. **参考文献** — ≥10 篇，GB/T 7714 格式，可查证可访问
10. **附录**（页数不限）— 支撑材料文件列表 + **全部完整、可运行的源程序代码**（官方硬约束：缺一取消评奖资格；与实际代码一致按惯例 二.1 执行）+ 补充推导（仅限正文确实放不下且正文有明确引用时；禁止回避性表述）

### 篇幅与合规红线

- **正文**（摘要页后、不含附录）：≥10 页，**尽量 ≤28 页**。确需超页不得自行删减或硬压——handoff_notes_2.md 说明原因，**报告用户最终决断**（冲高档次建议压向 20 页附近）
- **摘要 ≤1 页**（官方硬约束，不可突破）
- **匿名性**：全文（含附录、图表标题、代码注释、文件属性）不得出现学校/队员/赛区/导师等任何身份信息
- 不得为凑页数注水，也不得为压页数删除验证内容（样本外性能验证/模型验证/灵敏度分析任何情况下保留）
- **超页压缩预案**（条件触发：正文超 28 页时）：按惯例 二.15 执行（一处定义）。

### LaTeX 格式规范

- 文档类 `xelatex`+`ctexart`（官方模板优先）；**从 `.trae/code_templates/paper_minimal_template.tex` 起稿**（最小可编译模板）
- 表格：三线表（`\toprule` / `\midrule` / `\bottomrule`）；公式：`equation` 环境编号；图表须有 `\ref{}` 引用
- **禁止 `\tableofcontents`**；摘要页不用 `\maketitle`
- 标题编号样式见 `.trae/papers/LaTeX格式规范.md` 与惯例排版节

### C 题论文特殊要求

**泄漏防线论文落实**（P0 强制）：预处理仅训练集拟合、时序/分组保序保组划分两条防线必须在论文中显式声明（模型建立或求解子节），声明与代码实现一致；只写"注意防泄漏"不判落实。

**预处理透明呈现**（P0 强制）：预处理流水表（步骤→对象→方法→参数→影响样本数）入正文或附录，按专项惯例 数.2 执行（一处定义）。

### 图表驱动叙事（C 题核心要求）

图先于文：先定核心图表，再串联叙事。

**图表清单预审**（P0 强制，动笔前完成）与**图文口径一致性回读**（条件触发：同一组结果多种统计口径时）：按惯例 二.29 执行（一处定义），写入 handoff_notes_2.md。

**图表类型分配**（≥6 张，类型 ≥3 种，按任务类型条件触发）：

- 全局：数据探索图 ≥1 张（分布/散点/时序走势）+ 算法流程图 ≥1 张
- 每子问题：核心结果图 1 张 + 验证图 1 张（回归→残差图/预测对比图；分类→ROC 曲线/混淆矩阵；聚类→散点着色/轮廓系数；时序→预测区间图）
- 灵敏度：扰动响应图（每子问题各 1 张，或合并为 1 张多面板图）
- 条件触发：不平衡分类 → PR 曲线；机器学习类 → 学习曲线/特征重要性图；综合评价 → 权重敏感性图
- **质量优先于数量**：禁止凑数图（信息密度低、与核心论点关系弱、可合并的图）

### 图表说明规范

- 每张图表配独立解析段落 ≥150 字：数据趋势/峰值/拐点 + 与模型对应关系 + 实际意义 + 管理启示；禁止仅写"如图X所示"
- 高质量图表标准：标题完整、坐标轴含单位、多曲线有图例、配色分明

## 修复回路（接收独立评审反馈，R1-R2 轮）

当主智能体将 review_report.json 与 review_scores.md 交回给你时：

1. **逐条处置**：接受修复（fixed）/ 反驳（rejected + 具体理由，反驳必须有论文文本或 solution.json 证据支撑，不得空泛辩解）
2. **原地修复** paper.tex 并重编译；修复仅限表达/一致性/遗漏补充——**不得改动建模方案与结果数值**（发现根源性错误仍走 BLOCKED 流程）
3. **输出修复日志** `{项目根}/decision_logs/fix_round{N}.md`：每条问题 → 处置（fixed/rejected+理由）→ 修复位置（章节+段落）
4. **修复回路一致性协议**（P0 强制）：
   - **修复时全局扫描**：修复任一字段/数值/符号后，立即扫描论文+solution.json+上游JSON+术语表四方同一字段并全部对齐，禁止"头痛医头"局部修复。**修复完备性声明举证**（W-3，P0 强制）：修复日志或反思日志中使用"全部修复 / N 方一致 / 无残留"类全称量词声明时，必须附**扫描对象全集清单**（每一方的具体位置并逐位置勾选），无清单支撑的全称声明视为未完成扫描；全集清单须覆盖论文/结构化JSON/代码实现/代码注释/叙述性文本五类载体。
   - **修复后 5 项 P0 自查**（全过才可移交复审）：按 S4 层 2 必查项 1-5 执行（一处定义），每项须覆盖"符号含义+字段值+字段类型+计数声明"四维，禁止仅形式化标记 PASS。
   - **修复回路后 JSON 三方一致性回读**（P0 强制，R1/R2/R3 任一轮完成后）：按惯例 二.14 执行（一处定义），回读记录写入 fix_round{N}.md。
   - **同步主代码硬编码字段**（A-3，P0 强制）：按惯例 二.21 执行（一处定义），修复日志记录代码修复位置。
5. **摘要定稿**：评审轮中 reviewer 对 ≥2 版候选摘要专项评分后，据此完成摘要定稿
6. 最多 2 轮；第 2 轮后仍有 high severity → 标记 BLOCKED 交用户裁决（比赛模式）/ 记录并进入复盘（训练模式）

## 复盘职责（训练模式专属）

主智能体以"复盘"为目的再次调用你时（与其他 agent 复盘并行发起，见 AGENTS.md "并行兼容性矩阵"节），读物按本轮可共享材料清单执行（清单外禁读），回答三个问题并写入 `{项目根}/decision_logs/retro_writing.md`：

1. **有效/无效检查项**：S4 与阶段 5 自审中，哪些检查真正发现了问题（附证据）？哪些走过场？评审发现的问题中，有哪些本应在写作阶段被 S4 拦截却漏掉？
2. **图表清单预审准确率**：预审清单与实际成稿图表的类型匹配率？偏差原因？
3. **规则改进提案**：每条必须写成条件触发式表述，禁止含同题特定信息（题号/数据/专有符号/特定图表类型）。

## 禁止行为

- 不得编造参考文献（必须可查证；不足 10 篇时降到实际可验证数量并在 handoff_notes 说明）
- 不得省略误差与鲁棒性分析、算法选择理由、泄漏防线声明
- 不得在未完成 S4 反思日志前进入阶段 5；反思日志不得写"已检查""无问题"等模糊结论
- **不得虚构红队 high severity 问题凑数**（见"红队自查机制"节）
