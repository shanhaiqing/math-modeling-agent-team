## 层 3：红队自查（努力举证制）

**搜查目标**：令建模方案根本错误或假设不成立的问题。

| 搜查对象 | 检查结论与证据 |
|---------|---------------|
| R1 坐标单位陷阱 | 若坐标非 km，所有射程/覆盖判定全错。证据：603 条边逐条计算 长度/欧氏距离，mean=1.0000、std=0.0000、min=max=1.0000（geometry_check.py）→ 坐标即 km，无陷阱 |
| R2 图连通性陷阱 | 若目标节点不可达或存在孤立区域，Q3 转移/Q2 补给模型失效。证据：BFS 得 2 分量（413+23）；352/144/149 均在主分量；小分量 23 节点全苏军 → 已转化为隐含约束 H2（苏军孤立后方就地防御），不构成模型错误而是建模必须纳入的结构 |
| R3 附件数据完整性 | 端点校验 0 坏边、0 重复边、0 缺失；防御强度 ∈[0.01,1.0] 无 3σ 异常；横坐标 4 个 3σ 异常点经核视为东侧远端真实节点（X≈231-240，属战场东翼），非脏数据 → 数据可信 |
| R4 题目-附件一致性 | 题面装备参数（如天启 48t/35km/h/180km、V3 射程 16.8km）与附件二逐条一致；兵力数量仅见于题面（附件无）→ 以题面为准，已逐字回读 |
| R5 兵力-节点规模可行性 | 125 万动员兵 vs 268 个苏军节点 → 若按"人"建模变量值域 10^6，且单节点数万人不现实。处置：动员兵按万人粒度聚合（H9），其余装备按辆/门整数。该处置改变变量粒度但不改变最优结构，已登记为假设 |
| R6 装备数量极端不对称 | 盟军光棱火炮 14000 vs 苏军 V3 7000、盟军无远程数量劣势在坦克（340 vs 苏 480 中重坦）——若模型忽略射程差异会得出错误部署。处置：火力覆盖系数按射程×口径分层，Q1 目标函数显式区分直射/远程 |
| R7 "侦察机"语义 | 题面将侦察机列为"战略空袭单位"且"不宜部署过多防止被拦截"——名称与功能存在语义张力。处置：按题面功能定义（空袭单位）建模并设部署上限（H6），在 design_critique 中讨论该语义问题 |
| R8 破交概率无数据 | 题目要求"充分考虑敌方破交/拦截策略"但未给任何概率数据 → 若凭空设定单点值，结论不可信。处置：基线 0.15 + 敏感性 ±50% 扫描 + 蒙特卡洛传播（A-01），并在 HG1 争议点中声明 |
| R9 指挥节点"3 备选"评判维度 | 题目要求兼顾指挥通信距离、隐蔽性、抗毁能力，但三者均无直接数据字段。处置：通信距离=到己方部署节点平均路网距离（Dijkstra 预计算）；隐蔽性=1-防御强度暴露代理+低度数（不易被定位）；抗毁能力=防御强度——三维度代理指标全部可由附件数据构造，无需外部数据 |
| R10 时间盒风险 | 436 节点×6 单位×双方部署 MIP 变量约 5000+，Q2 VRP 结构 NP-hard。预判：Q1 用 HiGHS 可在时限内求解（线性化覆盖系数预计算）；Q2 若精确求解超时则按方法卡片 10 回退"构造启发式+局部搜索"并报告启发式统计（≥5 次运行）——验证项不删除 |
