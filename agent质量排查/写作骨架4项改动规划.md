## 一、范围与原则

**只写入 4 项模板骨架**，六段法摘要等散文式写作指导不写入（已被 paper-writer 覆盖，写入即违规重复定义）。

**三原则**（每次写入前自查，防过拟合铁律）：
1. **去 A 题痕迹**：剔除"物理机理建模/残差分析为 A 题默认"等倾向，改为 B 题/通用表述
2. **优化口径改造**：表格模板的统计口径（R²/RMSE）→ 优化口径（目标值/MIPGap/求解时间/敏感参数）
3. **条件触发式 + 分层**：每项标"条件触发：〈题型〉"，且不新增评审红线（红线判据仍以 paper-writer 为准，此处仅是"如何呈现"的写法骨架）

**落点统一**：[paper_minimal_template.tex](file:///C:/Users/35399/Desktop/数模B题专家团/.trae/code_templates/paper_minimal_template.tex) 就地层。paper-writer.md 不改（其 L70"以 paper_minimal_template.tex 为唯一基准"指针已覆盖，避免新增 prompt 条款膨胀）。

## 二、逐项规划

### 项 1｜模型检验小节骨架

- **内容**：残差分析 / 拟合优度 $R^2$ / 置信区间 / 交叉验证 / Bootstrap 的 LaTeX 骨架 + 每条一句写法提示
- **落点**：模板五节"结果验证与结果分析"子节（现 L217-218 统计类验证处），作为条件触发展开块
- **条件触发**：「统计拟合 / 回归预测类问题」；优化类用最优性验证（MIPGap 等），不适用本块
- **分层声明**：bootstrap/交叉验证/置信区间为**可选用增强手段**，非新增红线；评审红线仍以 paper-writer L53「残差/拟合优度/显著性检验」为最低必查
- **去 A 题**：改写作"含随机性数据的拟合/预测模型"而非"物理机理模型"

### 项 2｜模型对比分析表模板

- **内容**：三线表，列为「模型/算法｜目标值｜最优性指标（MIPGap/枚举完备性）｜求解耗时｜备注」
- **落点**：模板五节"模型求解"算法选择处（现 L211-213）后
- **条件触发**：「≥2 个模型/算法候选对比」时使用
- **口径改造**：模板原为统计口径（$R^2$/RMSE/MAE），改为优化口径——这是本项的核心改造点

### 项 3｜灵敏度分析表模板

- **内容**：五列「参数｜基准值｜变化幅度｜结果变化率｜灵敏度排序」，与 Tornado 图互补（表精读/图全览）
- **落点**：模板六节"灵敏度分析"Tornado 图处（现 L233-241）之后
- **条件触发**：「含灵敏度分析」时使用（原文已有 Tornado 图，表格作精读补充）

### 项 4｜双子图并排模板

- **内容**：`minipage` 0.49\textwidth ×2 并排子图示例（含 caption/子图标号）
- **落点**：模板六节灵敏度 figure 环境（现 L236-241）后，作为"多面板对比图"通用示例
- **条件触发**：「两相关图需并排对比」时使用
- **价值说明**：现有模板只有单图 figure，缺子图示例

## 三、注意事项

1. **不新增机查**：4 项均为写法/表格骨架，无独立可机查规则（表格列数/触发条件属 agent 判断，不编译进机查）。若未来出现"表格模板滥用成凑数"问题，再考虑机查。
2. **不改 paper-writer.md**：现有"以模板为唯一基准"指针已覆盖，避免「同一维度多处定义」重蹈质量排查期覆辙。
3. **注释女儿墙**：每项骨架用 `% 条件触发：...` 注释包裹，与现有模板注释风格一致（模板已用此风格标注"数据探索条件触发"等）。
