## 决策树

```
开始
  │
  ▼
Q1: 是否存在目标变量/标签（被解释、被预测、被评价的明确对象）？
  ├── 有（监督/有评价对象）──────────→ Q2
  └── 无（无标签，探索结构）─────────→ Q3
      │
      ▼
Q2: 目标变量是连续数值还是离散类别？
  ├── 连续数值 ──────────────────────→ Q2a
  └── 离散类别/等级 ─────────────────→ Q2b
      │
      ▼
  Q2a: 本题对该连续目标的任务是？（有无时间戳不在此处分叉，只写入 data_structure）
    ├── 预测未来值（有时间戳的序列外推）──→ Forecasting（时序预测）
    ├── 解释影响 / 估计关系 ──────────→ Regression（即使数据为时序/面板）
    └── 检验差异或关联 ──────────────→ Inference（可叠加 Regression）
      │
      ▼
  Q2b: 目标是由客观规则/数据生成，还是需主观赋权综合评价？
    ├── 客观标签/规则可定义 ─────────→ Classification（分类识别）
    └── 需构建指标体系综合赋权 ──────→ Evaluation（综合评价）
      │
      ▼
Q3: 任务目标是分组/结构发现，还是统计规律推断？
  ├── 分组/降维/结构发现 ────────────→ Q3a
  └── 检验/区间/关联显著性 ──────────→ Inference（统计推断）
      │
      ▼
  Q3a: 目标是样本分组还是变量压缩？
    ├── 样本分组 ────────────────────→ Clustering（聚类分群）
    └── 变量压缩/因子提取 ───────────→ Reduction（降维与因子）
      │
      ▼
Q4: 结论是否需衔接下游决策/优化（定价、补货、配置、调度）？
  ├── 是 ─→ 基本类型 + _Downstream，填写 downstream_decision_kind（卡片 12），续 Q5
  └── 否 ────────────────────────────→ Q5
      │
      ▼
Q5: 样本量与变量维度量级？
  ├── 小样本（<100）或高维（p≳n）───→ 标注 SmallSample/HighDim（方法选择避开大样本渐近法）
  ├── 中样本（100-10000）────────────→ 常规路径
  └── 大样本（>10000）───────────────→ 标注 LargeScale（优先可扩展算法）
      │
      ▼
Q6: 题目是否要求设计追加实验/采样点（再增加 N 次实验、如何选择测试点、序贯加点）？
  ├── 是 ─→ 基本类型 + ExperimentalDesign（必读卡片 13）
  └── 否 ─→ 结束
```

## 各类型特征速查

| 类型 | 目标变量 | 数据结构 | 典型指标 | 典型方法（卡片号） |
|------|---------|---------|---------|------------------|
| Regression（回归预测） | 连续 | 截面/面板/时序均可 | RMSE/MAE/R²/MAPE | 03, 05, 10 |
| Forecasting（时序预测） | 连续（预报未来） | 时间序列 | RMSE/MAE/MAPE | 04, 10 |
| Classification（分类识别） | 离散标签 | 截面 | 准确率/F1/AUC/混淆矩阵 | 05, 10 |
| Evaluation（综合评价） | 评价对象（需赋权） | 截面指标矩阵 | 综合得分/排序/权重敏感性 | 08, 07 |
| Clustering（聚类分群） | 无 | 截面 | 轮廓系数/CH/DB | 06, 07 |
| Reduction（降维因子） | 无 | 高维截面 | 方差贡献率/载荷 | 07 |
| Inference（统计推断） | 视问题 | 任意 | p 值/置信区间/效应量 | 09, 11 |
| Descriptive（描述统计） | 无 | 任意 | 分布/异常/趋势描述 | 02 |

## 边界情况处理

| 情况 | 处理 |
|------|------|
| 多任务复合（如先聚类再评价） | `task_types` 记数组，按子问题逐一归类；卡片按序组合 |
| 无时间戳、或时间仅为实验序号的曲线外推 | 主类型 **Regression**（卡片 03）；禁止因「外推下一期」判 Forecasting |
| 有时间戳但任务是影响/差异/关联 | 主类型 Regression 或 Inference；**禁止** Forecasting；时间形态只进 `data_structure` |
| 含下游优化决策 | 基本类型后标注 `_Downstream`，必读卡片 12，并填写 `downstream_decision_kind`（分叉一处定义见卡片 12） |
| 题目含追加实验点/采样点设计 | 基本类型上叠加 ExperimentalDesign，必读卡片 13；与 `_Downstream` 可同时成立 |
| 数据需自搜集（无官方附件） | 标注 SelfCollected，来源管理按惯例 一.22 执行，data_lineage 必填出处与检索日期 |
| 小样本 + 推断 | 标注 SmallSample，优先精确检验/自助法（卡片 09/10），禁用大样本渐近近似 |
| 高维 p≳n | 标注 HighDim，必先降维/正则化（卡片 07/05），禁止直接多元回归 |
| 无法明确归类 | 标注 Other，走第一性原理建模 + WebSearch 补充检索（fallback 路径） |

## 任务类型复核（GQ1 后，只增不减）

阶段 1 的树是初判。GQ1 按**每子问题输出形态**（预测值/类别/排序/区间/规律描述/方案）回写 `task_types`：

- **只增不减**：可增补 Descriptive、Inference 等树未走到的类型。
- **禁止删除**阶段 1 已判定的 Forecasting / Classification / Regression / Evaluation 等。
- **禁止**用第一问的类型覆盖整卷；禁止只凭单值 `problem_type` 打全卷。
- **不重走** Q1–Q6。

## 使用示例

```
题目：基于附件多年销售流水，分析各品类销售规律，预测未来一周补货量并给出定价建议

Q1: 有目标变量？→ 是（销量/销售额）
Q2: 连续数值 → Q2a
Q2a: 任务是预测未来一周销量 → Forecasting（日度流水写入 data_structure=time_series）
Q4: 需衔接下游决策？→ 是 → _Downstream，续 Q5
Q5: 样本量？→ 大样本
Q6: 要求追加实验点？→ 否
→ task_types 初判: [Forecasting]_Downstream
→ GQ1 复核只增不减: 第一问规律描述 → 增补 Descriptive
→ downstream_decision_kind: 补货/定价若能写成变量+目标+约束 → structured_planning，否则 rule_threshold
→ 卡片组合：01（预处理）→ 02（探索）→ 04（时序）→ 12（衔接优化）
→ 模式匹配：经典模式库"预测+决策衔接"模式
```
