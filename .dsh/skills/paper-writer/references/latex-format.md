# LaTeX 格式规范（CUMCM 论文）

> 用途：论文写作排版规范（2026-08 批次 2026-08-B1 瘦身版）。
> **导言区代码、表格/公式/图表示例代码一律以 `.trae/code_templates/paper_minimal_template.tex`
> （经完整论文实战编译验证）为唯一基准**，本文件只保留无法从模板推断的规范与硬约束。
> **`contest_profile=shuwei_en`**：改读 `赛制/shuwei_en.md` 与 `.trae/code_templates/paper_shuwei_template.tex`；本文件默认仍是国赛。

---

## 一、文档基础设置

- 文档类：`xelatex` + `ctexart`（当年组委会提供官方模板则优先官方模板）
- 页面：A4，页边距上下 2.54cm、左右 3.18cm（官方要求 ≥2.5cm）
- **行距：`\linespread{1.4}`**（LaTeX 默认行距偏紧，是"一眼不像国赛论文"的主因之一；
  不要写成 1.5 以上，会显得松散）
- 页码页脚居中、全文无页眉（`\pagestyle{plain}`）
- 导言区（字体/标题编号/宏包/代码排版）以模板为准，禁止自行更换代码排版宏包：
  **附录代码用 fvextra + `\VerbatimInput` 直引源文件**（`cumcm`：中文注释 100% 保留；`shuwei_en`：注释随正文英文）；
  不要用 listings（丢中文注释）或 minted（依赖 Pygments，易崩）

**两条结构红线（官方规范，违反直接扣分）**：

1. **禁止 `\tableofcontents`**——官方明确"不要目录"，目录白白占用正文页数。**`shuwei_en`**：不套本条，必须有目录（见 `赛制/shuwei_en.md`）。
2. **摘要页不使用 `\maketitle`**（会带入队名/日期，且不符合惯例）——摘要页只含：论文标题（黑体三号居中）+ 摘要正文 + 关键词，一页以内。**`shuwei_en`**：必须 `\maketitle`。

## 二、字体规范

| 元素 | 字体 | 字号 | 加粗 |
|------|------|:---:|:---:|
| 正文 | 宋体 (SimSun) | 小四号 | 否 |
| 西文/数字 | Times New Roman（`\setmainfont`；无该字体环境用 TeX Gyre Termes） | 随正文 | 否 |
| 数学公式 | newtxmath（与西文同族；禁止与 amssymb 同载） | 随正文 | 否 |
| 一级标题 | 黑体 (SimHei) | 三号 | 是 |
| 二级标题 | 黑体 (SimHei) | 四号 | 是 |
| 三级标题 | 黑体 (SimHei) | 小四号 | 是 |
| 图表标题 | 宋体 (SimSun) | 五号 | 否 |
| 表格内容 | 宋体 (SimSun) | 五号 | 否 |
| 页眉页脚 | 宋体 (SimSun) | 五号 | 否 |
| 参考文献 | 宋体 (SimSun) | 五号 | 否 |

## 三、标题编号（与国赛真实惯例一致）

```
一、   一级标题（黑体三号居中）
（一） 二级标题（黑体四号）
1     三级标题（黑体小四）
```

禁止使用 `1 / 1.1 / 1.1.1` 阿拉伯层级编号（与真实国赛论文惯例不符）。

## 四、内容排版要点（细则见模板对应环境）

- 表格：三线表（booktabs），禁止竖线，标题在表上方，正文须 `\ref{}` 引用
- 公式：`equation`/`align` 环境编号，变量首次出现须解释含义
- 图表：优先 PDF 矢量图（其次 PNG 300dpi），标题在图下方，正文须 `\ref{}` 引用；
  每张图表配 ≥150 字独立解析段落，禁止仅写"如图X所示"；**图幅宽度统一 `0.9\textwidth`**
  （多面板图可至 `0.95`，特殊构图例外须说明；<`0.8` 或未设 width 触发机查 WARN）
- 参考文献：≥10 篇，GB/T 7714 格式，正文 `\cite{}` 标注

---

## 五、编译命令

```bash
xelatex -interaction=nonstopmode paper.tex
xelatex -interaction=nonstopmode paper.tex   # 两次编译（交叉引用）
```

**禁止使用 `pdflatex`**（不支持中文）。用 `biblatex` 时中间换 `biber`。

## 六、常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| 中文显示为空白 | 未用 xelatex 编译 | 改用 xelatex |
| 字体缺失 | 系统无 SimSun/SimHei | Windows 自带，Linux 需安装 |
| 特殊符号（✓等）缺字形 | 中文字体无该字形 | 按模板 xeCJK 子分区路由到 Segoe UI Symbol |
| 参考文献 [?] | 未编译两次 | 再跑一次 xelatex |
| 表格超宽 | 列数过多 | 使用 `\small` 缩小字号或 `tabularx` |
| 附录代码中文注释丢失 | 用了 listings | 改 fvextra + `\VerbatimInput` 直引（`shuwei_en` 不要求中文注释，仍禁 listings） |

## 七、合规要点（官方格式规范硬约束，编译前逐项核对）

1. **摘要 ≤1 页**（含标题和关键词，无需英文翻译），摘要页起编页码（页脚居中，从"1"开始）。
2. **正文 ≤30 页**（摘要页之后起算，不要目录；>30 为 WRITING 门 ERROR。官方表述为"尽量控制在 20 页以内"）。**附录页数不限**。**`shuwei_en`**：Summary+目录+正文 ≤25，必须有目录。
3. **匿名性**：摘要页、正文、附录（含图表、代码注释）任何位置不得出现参赛者身份、学校、赛区信息。
4. **附录必含**：全部完整、可运行的源程序代码 + 支撑材料文件列表（缺可运行程序或程序结果与论文不符可取消评奖资格）。
5. **参考文献**：引用他人成果必须规范列出并在正文标注。
6. 若当年组委会提供官方模板，优先使用官方模板，本规范仅作补充。
