# 数据题专项惯例（stats 轨，跨题通用）

> T5 之前活流水线不读本文件。条款自 C 仓迁入，编号仍为数.1~数.n，与《国赛公开惯例.md》并行，不改其条款号。
> 判定原则：仅含跨题通用的数据方法学惯例，不含任何同题特定信息。

## 数.1 数据探索进正文（默认强制）

数据驱动类问题的数据探索（分布/散点/时序走势 → 初步规律 → 异常点识别与处置）必须作为模型建立的第一步写进正文对应问题小节，不得只放附录或省略。探索发现与后续建模选择的因果关系须显式写出（"因观察到 X 分布特征，故选用 Y 方法"）。对应卡片 02。

## 数.2 预处理透明报告

所有预处理步骤必须可复现地报告：缺失值处理方式与比例、异常值判据与处置数量、编码方式、标准化/归一化方法、特征构造公式。报告形式为预处理流水表（步骤 → 对象 → 方法 → 参数 → 影响样本数）。对应卡片 01。

## 数.3 数据泄漏禁区

任何使用目标变量或全体样本统计量的步骤（预处理拟合、特征选择、调参、降维），必须只在训练折/训练集内完成；时间序列与分组结构数据禁止随机划分（时序用滚动原点，分组用 GroupKFold）。solution.json 的 preprocessing 字段须含训练/测试隔离声明。对应卡片 01/10。

## 数.4 指标-任务匹配

评估指标必须与任务类型匹配并在论文中说明选择理由：回归→RMSE/MAE/MAPE/R²；分类→准确率仅适用于平衡数据，不平衡必报 F1/AUC/混淆矩阵；时序→滚动原点 backtest 误差；聚类→轮廓系数等内部指标 + 稳定性；评价→排序稳健性。指标与任务不匹配属 high severity。对应卡片 05/09。

## 数.5 数据扰动灵敏度

数据驱动模型的灵敏度分析须含"数据层面"扰动（替代 MIPGap 类优化专属验证）：输入特征 ±扰动、样本子集重抽样（bootstrap）、训练/测试划分随机性（多种子均值±标准差）三者至少其一，并报告结论的稳定性。对应卡片 10。

## 数.6 基线对比强制

任何复杂模型（机器学习、集成、深层网络）必须与至少一个简单基线（均值/线性模型/朴素时序/单变量规则）对比并报告提升幅度；无基线对比的复杂模型性能声明不可信，评审按 high severity 处理。对应卡片 05。

## 数.7 因果表述分级

全文因果措辞须符合卡片 11 分级表：仅相关证据写"相关/关联"；控制混杂后写"关联依然显著"；有准实验设计方可写"因果效应"。题目问"影响"时在假设或讨论节声明识别局限。"相关即因果"越界表述属 high severity。对应卡片 11。

## 数.8 衔接口径一致（条件触发：含下游决策）

若数据结论作为下游决策/优化模型输入（特征指纹 `downstream_optimization = yes`），则：每个下游输入可追溯至上游具体产出；口径（定义/单位/时间粒度/样本范围）逐项核对；关键输入带不确定性且下游做扰动/情景分析；并按卡片 12「下游模型族分叉」填写 `downstream_decision_kind`（结构化规划 → 变量+目标+约束的开源规划或 P4 借卡，禁止拟合代替决策器；规则/阈值留 C；排队走分布拟合+蒙特卡洛）。对应卡片 12。

## 数.9 评价类稳健性（条件触发：综合评价任务）

若为综合评价任务，排序/分级结论必须配稳健性证据：权重扰动（±20%）或换集结方法对照，名次稳定性须报告；AHP 类主观赋权必须报一致性比率 CR<0.1。对应卡片 08。
