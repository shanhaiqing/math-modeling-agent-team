# G3 · 论文初稿审查（DRAFT_REVIEW，必过）

> 类型：必过 · 人工 · 30 分钟
> 记录：`gate_decisions.jsonl`，`gate_id=G3`

## 目的

在花一整轮独立评审之前，先确认初稿的故事、结构、摘要和合规没有硬伤。**不要用独立评审去发现初稿级问题。**

## 决策包（一页）

| 区块 | 内容 |
|---|---|
| 状态 | run_id / 页数 / 用时 / 成本 / 建议 |
| 摘要 | ≥2 版候选 + 推荐版 + 定量结论检查 |
| 结构 | 10 项结构是否齐全；是否按问题组织 |
| 合规 | 页数、摘要一页、匿名、参考文献、附录代码、目录/页眉（按赛制） |
| 机查 | ERROR=0；需人裁定的 WARN 逐条列出 |
| 风险 | ≤5 条：评审最可能打回的点 |
| 建议 | 批准 / 退回写作 / 退回建模 / 退回图 / 停止 |

## 人工要看的只有

1. 摘要是否按问题分段、结论是否定量？
2. 故事线是否成立：问题→模型→求解→验证→灵敏度→评价？
3. 图表是否在正确的位置、解析段是否够？
4. 页数/匿名/附录代码是否合规？
5. 有没有"评审一定会打回"的明显问题？

## 选项与去向

| 选项 | 去向 | 退回内容 |
|---|---|---|
| `approve` | REVIEW | 绑定 hash；进入独立评审 |
| `return_writing` | WRITING | 表达/结构/摘要/合规问题 |
| `return_modeling` | MODELING | 数值/模型根源性问题；内核写 rework brief |
| `return_figures` | FIGURES | 图面问题 |
| `stop` | STOPPED | 记录原因 |

## 退回上限

- 写作退回最多 2 次；建模退回计入全局建模返工 ≤3。
- 再退回仍不达标 → 人工接受 + 记录风险，或停止。

## 禁止

- 把初稿级问题留给 reviewer。
- 在页数/匿名/附录代码未过时放行。
- 只读摘要不读正文；至少抽查两节正文。
