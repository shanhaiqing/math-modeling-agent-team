# G5 · 交付确认（DELIVER）

> 类型：必过 · 人工 · 10 分钟
> 记录：`gate_decisions.jsonl`，`gate_id=G5`

## 目的

提交是外部动作，必须由人确认文件清单、MD5 和合规勾选。这不是质量判断，是交付控制。

## 决策包

| 区块 | 内容 |
|---|---|
| 文件 | 论文 PDF、支撑材料、源程序、数据；路径与大小 |
| MD5 | 生成时间、文件清单、哈希值 |
| 合规 | 页数、摘要一页、匿名、参考文献、附录代码、命名 |
| 机查 | compliance ERROR=0；packaging ERROR=0 |
| 备注 | 未解决风险、赛制特殊要求 |

## 选项与去向

| 选项 | 去向 | 说明 |
|---|---|---|
| `deliver` | DELIVERED | 记录 MD5；不再改文件 |
| `stop` | STOPPED | 记录原因 |

## 人工要确认的只有

1. 文件名、题号、队号是否符合当届通知？
2. MD5 是否在最后一次改动之后生成？
3. 支撑材料是否只含代码/数据/图表，没有内部 JSON？
4. 附录是否含完整可运行源程序？
5. 是否还有未解决的高风险项需要带风险交付？

## 铁律

- **MD5 生成后不得再改任何文件。**
- 交付确认一旦记录，后续改动必须重新走 COMPLIANCE 和 G5。
- 不得由 agent 代替人点击交付。
