# G2 · 建模 + 方法 + 成图审查（MODEL_REVIEW，必过）

> 类型：必过 · 人工 · 30 分钟
> 记录：`gate_decisions.jsonl`，`gate_id=G2`

## 目的

一次看完"建模 + 方法学结论 + 成图"，决定是否进入写作。**批准绑定 artifact hash**；之后任何被批准物改动都会让本门失效。

## 决策包（一页）

| 区块 | 内容 |
|---|---|
| 状态 | run_id / 用时 / 成本 / 建议 |
| 关键结果 | 每子问题：目标值/指标、验证方式、灵敏度、关键假设（≤10 行） |
| 方法结论 | verdict、闸门一句、票与处置 |
| 图 | 6 张缩略图 + claim + 数据来源；hero 图单独标 |
| 机查 | ERROR=0；需人裁定的 WARN 逐条列出（带文件/行号） |
| 风险 | ≤3 条：最可能让论文失分的点 |
| 成本 | 已用/剩余时间、token、人工分钟 |
| 建议 | 批准 / 退回建模 / 退回图 / 停止 + 理由 |

## 人工要看的只有

1. 问题归类与假设有没有硬伤？
2. 数值量级是否合理？最优性/模型验证/灵敏度是否都在？
3. 方法结论与票是否接受？
4. 图是否遮挡、字号可读、claim 成立？hero 图是否值得？
5. 有没有"现在不拦、写作阶段会爆炸"的风险？

## 选项与去向

| 选项 | 去向 | 退回内容 |
|---|---|---|
| `approve` | WRITING | 绑定 hash |
| `return_modeling` | MODELING | 数值/模型/方法问题；内核写 rework brief |
| `return_figures` | FIGURES | 图号 + 缺陷 + 建议；不写 modeling brief |
| `stop` | STOPPED | 记录原因 |

## 退回路由

- 数值、模型结构、求解、验证缺失 → Solver
- 方法错配、算法类选错 → Solver（G1 已处理；G2 反悔同样走 rework）
- 图面：轴缺单位、图型错、遮挡、缺图、claim 不成立 → Figures
- 表达/一致性 → 不在本门处理，留到 G3

## 退回上限

- 图面退回最多 2 次；建模退回计入全局建模返工 ≤3。
- 再退回仍不达标 → 人工接受 + 记录风险，或停止。

## 禁止

- 只看图不看数值；只看数值不看图。
- 把图面问题退回 solver（浪费一轮）。
- 批准后静默改 solution/figures；hash 会失效。
